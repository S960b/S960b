# Twisted Vigenere — GlacierCTF 2026

[Русская версия](README.ru.md) · [Full technical write-up](solve.md)

**Category:** crypto · **Points:** 50 · **Status:** Solved, accepted by the CTF platform (participant report).

The so-called Vigenère cipher is a repeated-key **XOR** cipher. Its “plaintext” is generated by Python `random.randbytes(2536)` (MT19937), and the repeated XOR key is **the flag itself**.

## The recovered answer

Our independent analysis of the **unaltered organizer handout** recovers the following from the 2536 ciphertext bytes, assuming a 48-byte ASCII flag with the known `gctf{` framing:

```text
gctf{from_rand0m_!mpor+_n0+_s0_r4nd0m_af+3r_???}
```

The last **three bytes** do not affect the available MT19937 next-block consistency equations. The earlier accepted flag resolves them. That accepted 48-byte value passes all **320** recovered MT19937 constraints (zero mismatches). We distinguish this from mathematically unique recovery: **the ciphertext alone leaves these bytes underdetermined**.

## Reproduction

The [source-based write-up](solve.md) explains MT19937 tempering, the 624-word state, the ten additional words, a 384-bit linear model over GF(2), and why only 45 bytes can be identified.

The [pure-Python solver](scripts/solve_mt.py) takes the official `output.txt` from the [original handout](https://play.glacierctf.com/challenges#Twisted%20Vigenere-6):

```sh
python3 scripts/solve_mt.py /path/to/twisted-vigenere/output.txt
```

No `numpy`, SageMath, Z3, or network connection is needed. An optional second argument verifies a proposed 48-byte candidate against the original MT19937 constraints. It does **not** assume or contain the accepted flag as a hardcoded constant.
