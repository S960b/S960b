# Fishies: ход решения

[English](solve.md)

## 1. Задача

Приложение для обмена рыбками и бот на Puppeteer. Цепочка объединила XSS, небезопасное рекурсивное слияние объектов и наследование настроек запуска браузера.

Материалы: `server.js`, package files, Handlebars template; saved later successful download evidence and earlier Git-bridge investigations.

## 2. Разбор

Самописный `escape()` меняет `<` и `>` на длинные HTML-entities внутри строки, но после замены слишком сильно увеличивает индекс. Соседние скобки позволяют оставить рабочий HTML-тег. `POST /api/fish/:id/report` запускает Puppeteer с HttpOnly-cookie администратора. Выполненный ботом JS может вызвать защищённый `PATCH /api/admin/fish/:id/fishData`. Его `combine(target,source)` не фильтрует `__proto__`, позволяя менять `Object.prototype`. Аудит Puppeteer 25.16.0 подтвердил, что Chromium получает унаследованные `env`-настройки.

## 3. Последовательность действий

1. Создать рыбу с соседними угловыми скобками и `img onerror`, затем отправить её на модерацию.
2. В контексте бота вызвать admin PATCH с вложенным `__proto__`, вызвав prototype pollution. HttpOnly-cookie читать не нужно.
3. В ходе расследования был подтверждён примитив управления `env` дочернего Chromium; дополнительно исследовали `downloadBehavior` для записи библиотеки, загружаемой следующим запуском браузера. В более позднем архиве зафиксирован успешный результат с файлом `/static/dl/flag.txt`.
4. Прочитать появившийся файл через публичную статику и остановить временные слушатели.

## 4. Что подтверждено

`server.js` показывает ошибку экранирования, админ-бота, PATCH и небезопасный merge. Git-мост ранее подтвердил XSS в браузере бота и наследование `env` локально; поздний `evidence/solve_2.txt` содержит реальное обращение к `/static/dl/flag.txt`, после которого зафиксирован флаг. Старый отчёт «флага нет» относится к попытке до этого успеха.

**Результат:** 1 принятый флаг(а), в открытом репозитории скрыты (`PP{...}`).

## 5. Что не сохранилось

Не сохранился полный JS-payload в браузере, код `.so`, настройки скачивания и полный stdout успешного прогона. Поэтому подтверждённые примитивы отделены от реконструкции промежуточных шагов.

## 6. Меры защиты

Применять корректное контекстное HTML-экранирование, не допускать исполняемый пользовательский HTML, фильтровать ключи `__proto__`/`constructor`/`prototype` при merge и изолировать привилегированного бота.
