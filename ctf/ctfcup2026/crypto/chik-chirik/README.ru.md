# Chik Chirik

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 229
- **Категория:** крипто / misc / аудио
- **Задача:** https://game.ctfcup.online/tasks/chik-chirik
- **Файлы:** `capture.wav` и бинарь `transmitter`
- **Флаг:** `ctfcup{...}` (скрыт)

Запись это цифровой сигнал: 1016 частотных чирпов по 2048 отсчётов на символ, восемь состояний символа, преамбула `24355342`. Символы несут код Рид-Соломона RS(7,3) над GF(8), а кодовые слова затем перемешиваются линейным генератором xorshift128.

Декодирование даёт 144 кодовых слова без остаточных ошибок. Закон кадра `B = ceil(8(L+4)/3)` фиксирует payload в 50 байт, два утёкших бита на символ дают линейную систему ранга 128 для состояния генератора, а обращение перемешивания вместе с CRC32 даёт флаг. Состояние, восстановленное из записи: `8bf31bf8 886c0791 8d3e0dc3 1557904c`, CRC32 `2a2617cc`.

Солверы в `scripts/`: `solve_chirp.py` для WAV и `solve_from_octal.py` для уже демодулированного октального потока.
