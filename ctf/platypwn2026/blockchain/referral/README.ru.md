# Referral

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** blockchain
- **Сложность:** 2
- **Исходники:** `Proxy.sol`, `Chal.sol`, `Setup.sol`
- **Флаги:** 1 принято (`PP{...}`)

Самодельный прокси и логический контракт используют несовместимую раскладку storage. Обновление реферала перезаписывает адрес реализации.

**Причина:** У `Proxy` нулевой слот — `implementation`, первый — `admin`. У `Chal` первая переменная `latestReferrer` также лежит в нулевом слоте. Вызовы выполняются через `delegatecall`, следовательно запись `latestReferrer = referrer` из `deposit` попадает в storage прокси и меняет адрес реализации.
