# Fortune Teller - format string, переключение глобального флага

- **Платформа:** FortiD CTF 2026
- **Категория:** Pwn
- **Автор:** ipaljak
- **Очки / Решения:** 106 очков, 389 решений
- **Дата:** 2026-10-09
- **Remote:** `fortune-teller-<...>.inst15.ctf.fortid.com:1337` (TLS/ncat, закрыт после события)
- **Флаг:** `FortID{...}` (замаскирован)
- **Бинарь:** `fortune` (исходник `chall.c` в комплекте)
- **Защиты:** Full RELRO, stack canary, NX, PIE
- **Описание (официальное):** "The oracle will answer any question 🔮, you might even get blessed with a flag..."

Сервис с меню: спросить у оракула вопрос, получить благословение. `ask_oracle()` передаёт пользовательский ввод прямо в `printf()` - неконтролируемая формат-строка. `win()` печатает флаг, но вызывается только из `receive_blessing()`, и только когда глобальная `blessing == 0x1337`. Эксплойт: ликаем базу PIE через позиционные указатели, переключаем blessing записью `%4919c%8$hn`, получаем благословение.

Файлы:

- `solve.md` - полный ход решения, включая dead ends (английский)
- `solve.ru.md` - тот же ход решения на русском (рабочая копия)
- `scripts/solve.py` - адаптивный remote-эксплойт (на нём взят флаг)
- `scripts/repro.py` - минимальная локальная репродукция
