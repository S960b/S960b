# Maker-отбор (этап 1): промежуточный отчёт и как воспроизвести

Дата: 2026-10-03 (UTC). Статус: сбор данных ИДЁТ (6ч из 360 мин запланировано,
затем продление до 48ч по одобренному плану). РЕАЛЬНЫЕ ОРДЕРА НЕ ВЫСТАВЛЯЮТСЯ.

## Контекст

Старая гипотеза (taker-запаздывание цены SafeTrade к внешним биржам) закрыта
(CLOSED в findings_full_run.md): два пригодных up-наблюдения дали −107…−165 bps
после комиссий. Новое направление — maker на SafeTrade (лимитные заявки, PMM-идея
из Hummingbot). ТЗ: автономный бот, который сам выставляет/отменяет заявки,
учитывает исполнения, ограничивает позиции, останавливается при ошибках.

Этап 1 = отбор рынка БЕЗ ордеров (техническая и экономическая пригодность).

## Команды (как воспроизвести)

```bash
# 1. Широкий отбор всех 100 USDT-пар SafeTrade (~18 мин при 20 req/мин)
./venv/bin/python cli.py maker-screen --depth-snaps 2 --trade-pages 3 --rpm 20 --verbose
# -> reports/pair_screen_maker.csv / .json

# 2. Детальный сбор финалистов (этап 1.3): depth 20с, trades 60с, oracle LTC 100с
./venv/bin/python cli.py maker-collect --pairs PRLUSDT,QUANTUSUSDT,TSCUSDT,USDCUSDT,LTCUSDT \
    --minutes 360 --rpm 20 --verbose
# -> data/maker/<run_id>/{depth,trades,oracle}.jsonl + manifest/summary

# 3. Анализ сбора: распределения spread/глубины/активности
./venv/bin/python maker/detail_analyze.py --run-id mk_xxx --data-dir data/maker --verbose --json-out reports/...
```

## Ключевые решения (по поправкам ревью)

1. Широкий спред НЕ исключает пару — для maker это повод проверить встречную
   торговлю; спред вычитается только при пересечении стакана (вынужденная продажа).
2. Активность меряется ВРЕМЕННЫМ ПОКРЫТИЕМ: сделки/час, возраст последней сделки,
   медианная пауза. Число страниц trades (history_truncated) НЕ равно «нет торговли».
3. Пагинация trades: page=N работает (проверено: page=2 даёт следующую сотню).
   При невозможности дочитать — trade_coverage=history_truncated/coverage_unknown.
4. Единый rate limiter SafeTrade (20 req/мин по умолчанию), считает ВСЕ вызовы
   (depth+trades+markets), backoff при 429. 30с НЕ считается лимитом биржи.
5. min_qty × last_price — предварительный min_notional; fee_unverified, пока не
   подтверждено для конкретного рынка (config maker_bps=0 НЕ считается фактом).
6. Внешние биржи — только ориентир цены для финалистов (LTC: Binance/OKX/Bybit);
   наличие пары на 3 биржах НЕ условие отбора.
