# filter

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** pwn
- **Задача:** https://game.ctfcup.online/tasks/filter
- **Файлы:** `filter.tar.gz` с `filter.c`, `model.h`, `gen_model.py`, `Makefile`
- **Флаг:** `ctfcup{...}` (скрыт)

Раннер шеллкода, который оценивает присланные байты небольшой трансформерной моделью и исполняет их только при неположительной оценке. Вход это 4-байтовая little-endian длина и сырые байты, буфер отображается как `PROT_READ | PROT_WRITE | PROT_EXEC`.

Модель это замаскированный тест на биграммы: `gen_model.py` строит веса аналитически так, чтобы сеть совпадала с оракулом на трёх парах, `0f 05`, `cd 80` и `0f 34`. Всё остальное в коде игнорируется.

Поскольку guard читает байты один раз, а отображение остаётся записываемым, payload на 39 байт несёт `0f 04` и одну инструкцию, переписывающую следующий байт в `05` прямо перед тем, как до него дойдёт процессор. Guard сообщает `score = -10.000`, а процесс исполняет настоящий `execve("/bin/sh")`, который читает флаг из `/flag.txt`.

Солвер: `scripts/solve_filter_remote.py` (умеет тикет гейтвея). Сырой прогон: `evidence/filter_run.log`.
