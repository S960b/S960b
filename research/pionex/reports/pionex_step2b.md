# Pionex — шаг 2б: строгий денежный расчёт funding carry (по аудиту)

Модель переписана полностью. Нового сбора данных не было — пересчёт по
тем же 500 funding-выплатам + 8H klines spot/mark (догружены только свечи).

## 1. Определения и формулы

- q = постоянное количество базового актива (q=1 в расчёте; масштаб линеен);
- S_t = цена spot (close 8H-свечи), F_t = mark цена perp (close 8H свечи);
- B_t = F_t − S_t (премия perp к spot);
- позиция: long spot q + short perp q (направление нейтрально);
- price_PnL = q·((S_T − S_0) + (F_0 − F_T)) = q·(B_0 − B_T):
  расширение премии B => убыток, сужение => прибыль;
- funding (official Pionex, blockchain-fee blog, проверено 2026-10-06):
  Funding Fee = Position Value × Funding Rate, ставка в долях (не bps);
  positive => long платит short. Для нашей позиции (short perp) получаем:
  funding_USDT = Σ_i q·M_i·r_i, где M_i = mark_i (неитион = mark × size,
  size = q, марк на момент выплаты), r_i — ставка в долях;
- fees: 4 операции со своими номиналами и раздельными ставками spot/perp:
  fees = q·S_0·f_s + q·F_0·f_p + q·S_T·f_s + q·F_T·f_p;
- net_USDT = funding_USDT + price_PnL − fees;
- C0 = q·(S_0 + F_0) — gross capital: spot cost + futures collateral,
  сценарий без плеча с отдельным залогом (внесённые средства = C0).
  gross exposure (2·q·notional) ≠ внесённые средства — ROE на C0.
- Margin path НЕ проверялся: расчёт без проверки возможности удержания
  позиции (при росте spot короткая perp может потребовать дополнительную
  маржу — помечено как непроверенное).
- Цены на момент выплаты: последняя ЗАКРЫТАЯ 8H-свеча до t (без lookahead),
  возраст цены (age_h) фиксируется; выплаты без данных — непокрытые.

Фрагмент кода (scripts/pionex_carry_v2.py):
```
funding_usdt = sum(q * r['m'] * r['r'] for r in covered)   # short perp: +q*mark*rate
price_pnl    = q * ((ST - S0) + (F0 - FT))                  # = q*(B0 - BT)
fees         = q * (S0*fee_s + F0*fee_p + ST*fee_s + FT*fee_p)
net          = funding_usdt + price_pnl - fees
C0           = q * (S0 + F0)
```

## 8. Вывод (честно)

- При fee 5 bps на ногу положительный net за 166 дней у всех кандидатов,
  но устойчивость сильно разная: 90d-окна ВСЕ положительны только у AAVE
  и ARKM; у AMZNX 99.1%, у AAPLX 84%.
- Короткие 7d-окна отрицательны в 64–94% случаев (кроме AR/AMZNX 35–43%)
  — funding-кэш не является плавным доходом, чувствителен к basis-движениям.
- Годовая проекция (условное масштабирование, НЕ прогноз): AAVE ~2.2%/год,
  AMZNX ~4.2%/год, AAPLX ~1.7%/год на gross capital при fee 5 bps.
- Это по-прежнему НЕ подтверждение доходности: нет слайпеджа, нет margin
  path, комиссии — стресс, 500 выплат — 166 дней. Следующий шаг (WS 24ч
  p50/p90 спредов, объёмов, staleness, basis) — после твоего решения.
