# Вентилятор303 (misc)

Задача про аудиозапись радиоэфира. Дано: `ventilator303.wav` длительностью 168 секунд и текст
про балканскую станцию, которая передавала в эфир что-то полезное для домашних компьютеров,
с датой 19 апреля 1987 года. В записи речь, служебные сигналы и цифровая передача программы.

Что с записью:

- Несжатый PCM, один канал, 16 бит, 44 100 Гц, около 14,8 МБ. SHA-256
  `65c389277d5c21bb0dba559147884053f124756e2c8e35c8c5909bf4a70a05c5`.
- Цифровой участок это AFSK с тонами 1200 и 2400 Гц при 1200 бод, кадры 8N1, синхронизация по
  преамбуле из байтов `0x55` на 14.99 секунды.
- Внутри сигнала идёт текстовый заголовок `VENTILATOR-303 TAPE v1` с полями `FORMAT: ZXTAP`,
  `LEN: 16659` и `CSUM: 88D9`. Контрольная сумма это CRC-16/CCITT-FALSE от всего файла.

Что получилось после декодирования:

- ZX Spectrum TAP на 16 659 байт, SHA-256
  `033e4ea05b182ba025468a8611c5bac7337a6388ab28b93037b4497977b45655`, совпадает с
  приложенным файлом побайтно.
- Четыре блока: заголовок BASIC, данные BASIC на 163 байта, заголовок машинного блока и
  машинный блок на 16 450 байт. XOR каждого блока равен нулю.
- BASIC грузится с автозапуском со строки 10, машинный код на 16 448 байт грузится по адресу
  `0x8000`, из них 15 378 байт это наполнитель `0x5A`.

Что нашлось в коде:

- Цикл на 43 символа по адресу `0x82A2`, условие выхода `CP 0x2B`.
- Начальное состояние генератора по `0x83D4` это `0x19870419`, то есть дата из задания.
- Генератор по `0x8202`: умножение на `0x41C64E6D` и прибавление `0x3039` по модулю `2^32`.
- Ключевой байт берётся из битов 16..23 состояния (адрес `0x83C6`), шифротекст лежит по
  `0x8403`, порядок символов задаёт таблица перестановки по `0x83D8`.

Файлы:

- `scripts/01_wav_to_tap.py` - декодер AFSK и UART, восстанавливает TAP из WAV
- `scripts/02_tap_to_flag.py` - проверка блоков TAP, извлечение кода Z80 и расшифровка строки
- `scripts/03_spectrum.py` - спектрограмма фрагмента через numpy и matplotlib
- `assets/ventilator303.tap` - восстановленный TAP
- `assets/fsk_detail.png` - спектрограмма участка цифровой передачи, построена третьим скриптом

Сама запись на 15 МБ в репозиторий не копируется, она выдана в условии задачи.

Полный путь решения описан в `solve.ru.md`.
