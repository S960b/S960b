# Flag on the flag (OSINT)

[English version](README.md) · [GlacierCTF 2026](../../README.ru.md)

- Автор: LosFuzzys
- Баллы: 50
- Сложность: easy
- Формат флага: `LosFuzzys{.*}`

## Задача

В сохранившейся карточке задания говорилось, что команда приносит с собой собственный счастливый флаг. Значит, исследовать требовалось не сервис и не бинарник, а физический флаг/баннер команды LosFuzzys.

Решение полностью OSINT: найти достаточно чёткую фотографию фиолетового баннера LosFuzzys, заметить строку из hex-байтов по нижнему краю, декодировать её XOR с `0x42` и восстановить скрытый суффикс. На первых подходящих фотографиях последний байт закрывала складка ткани, поэтому первый кандидат оказался короче правильного флага на один символ.
