# Пропавший архив (crypto)

В задаче два файла: `generate.py` и `output.txt`. Название отсылает к исходному архиву,
который был утерян и восстановлен из веб-архива, от него остались генератор и его вывод.

Что делает `generate.py`:

- `E = 65537`, четыре независимых RSA-инстанса, простые числа по 1024 бита, модуль около
  2048 бит.
- Флаг длиной 32 байта режется на четыре чанка по 8 байт.
- Каждый инстанс шифрует один чанк, дополненный слева 24 случайными байтами, то есть
  сообщение занимает 32 байта, а чанк стоит в младших 8 байтах.
- Для каждого инстанса в вывод дополнительно попадает `h`, 518 старших бит одного из
  простых множителей, то есть `h = p >> 506`.

`output.txt` начинается с `4`, `65537`, `32`, дальше идут четыре тройки `(n, c, h)`.

Цель: восстановить все четыре чанка, склеить их по порядку и получить флаг в формате
`SOLARCTF{...}`.

Файлы:

- `assets/generate.py`, `assets/output.txt` - условие в исходном виде
- `scripts/solve_rsa_partial.py` - солвер
- `scripts/run_kali.sh` - обёртка, ставит локальные зависимости и запускает солвер

Полный путь решения описан в `solve.ru.md`.
