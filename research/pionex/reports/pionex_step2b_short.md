# Pionex шаг 2б: строгий денежный расчёт carry (по аудиту)

Пересчёт по тем же 500 выплатам + 8H klines spot/mark. Нового сбора нет.

1. ОПРЕДЕЛЕНИЯ. q=const базовый актив (q=1); S=spot close 8H, F=perp mark close 8H;
B=F−S. Позиция long spot q + short perp q.
price_PnL = q*((S_T−S_0)+(F_0−F_T)) = q*(B_0−B_T) — расширение B убыток, сужение прибыль.
funding (official: Funding Fee = Position Value × Rate; positive => long платит short):
funding_USDT = Σ q*mark_i*r_i (r в долях).
fees = q*S_0*f_s + q*F_0*f_p + q*S_T*f_s + q*F_T*f_p (4 операции, раздельные ставки).
net = funding + pricePnL − fees. C0 = q*(S_0+F_0) = gross capital (spot+perp collateral,
без плеча). Margin path НЕ проверен. Цены — последняя ЗАКРЫТАЯ 8H свеча до t (без
lookahead), age фиксирован. Фрагмент кода: файл scripts/pionex_carry_v2.py.

2. КОНТРОЛЬНЫЕ ПРОВЕРКИ (q=1): P1 B+1bps,fee0 -> net−0.01<0 (убыток) OK;
P2 B−1bps -> +0.01>0 (прибыль) OK; P3 цены const, funding0, fee1bps*4 -> −0.04=−fees OK.
