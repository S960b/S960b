# FSenc: ход решения

[English](solve.md)

## 1. Условие и данные

Реверс файлового шифровальщика. Ключевой момент — разметка заголовка зашифрованного файла. Исходные материалы: Preserved decryption/Argon2 test commands; original encrypted data files not included.

## 2. Анализ

Сохранённая команда берёт байты `12:56` файла `flag.bin` как 44-байтное поле: первые 32 байта — ключ ChaCha20-Poly1305, следующие 12 — nonce. Шифртекст начинается с байта 56. Проверка вызывает `ChaCha20Poly1305(key).decrypt(nonce, body, None)`. Отдельно пробовали Argon2id с `time_cost=2`, `memory_cost=19456`, `parallelism=1`, длиной 44 байта и детерминированной солью. Но лог не доказывает, что перебор пароля был нужен.

## 3. Как получен результат

1. Разобрать формат как `magic (12 байт) | header (44 байта) | ciphertext`.
2. Разделить заголовок на `key=header[:32]` и `nonce=header[32:44]`.
3. Проверить расшифровку `data[56:]` через ChaCha20-Poly1305 без AAD.
4. Эксперимент с Argon2id и словарём записан отдельно; не приписываем ему успешное восстановление ключа без сохранившегося результата.

## 4. Подтверждение

В архиве есть команды для проверки заголовка и Argon2id. Агент пометил задачу решённой, но файл с выводом расшифрованного текста отсутствует.

Результат: **1 флаг(а) принято**, содержимое замаскировано `PP{...}`.

## 5. Ограничения воспроизведения

Не приложены `flag.bin`, исполняемый файл шифровальщика и успешный вывод расшифровки. Полное воспроизведение по архиву сейчас невозможно.

## 6. Защита и вывод

Ключ нельзя сохранять рядом с шифртекстом как незашифрованные метаданные. Nonce может быть публичным, ключ — нет; метаданные необходимо аутентифицировать.
