# Ron's Revenge: ход решения

[English](solve.md)

## 1. Условие и данные

Потоковый шифр на основе RC4 с состоянием 2048 элементов и выбираемым клиентом IV. Исходные материалы: `server.py`; exploit process check/log path (actual exploit absent).

## 2. Анализ

Сервис создаёт долгосрочный ключ из восьми слов, добавляет перед ним три слова IV от клиента и шифрует один и тот же флаг. В состоянии 2048 значений, каждый выход RC4 занимает 11 бит и упаковывается в байты. Из известного префикса `PP{` можно получать начальные биты гаммы; смещения KSA остаются статистически уязвимыми даже при большом состоянии.

## 3. Как получен результат

1. Запросить шифрование с серией специально выбранных трёхсловных IV, сохранить шифртексты.
2. XOR первых байтов с известным префиксом `PP{` и извлечь биты гаммы.
3. По слабым IV использовать FMS-подобное голосование для последовательного восстановления восьми слов неизвестного ключа, учитывая уже найденные слова.
4. Ранжировать кандидатов по частотам, проверять их на дополнительных ответах сервиса и затем расшифровать весь флаг.

## 4. Подтверждение

Из исходника точно известны схема ключа 3+8 слов, `state_size=2048`, управляемый IV и упаковка 11-битных значений. В ходе решения работал `ronsrevenge_exploit.py`, однако архив содержит только команду проверки процесса и лога, не сам скрипт. Флаг принят.

Результат: **1 флаг(а) принято**, содержимое замаскировано `PP{...}`.

## 5. Ограничения воспроизведения

Не сохранились таблицы голосований и код эксплойта; конкретные IV, количество проб и слова ключа нельзя надёжно восстановить.

## 6. Защита и вывод

Нельзя использовать RC4-подобный KSA с выбираемым пользователем префиксом ключа. Для шифрования подходит стандартный AEAD с уникальным nonce.


## Оригинальный решающий скрипт

Найден оригинальный FMS-солвер: KSA RC4-2048, голосование по слабым IV, извлечение 11-битного слова из известного двухсимвольного префикса, проверка полного ключа и локальный --selftest. В публичной версии тестовый искусственный текст заменён маркером, не похожим на реальный флаг.

```bash
python3 scripts/ronsrevenge_exploit.py <host> <port>
```

Код: [scripts/ronsrevenge_exploit.py](scripts/ronsrevenge_exploit.py). Параметры и проверки находятся в файле, адрес инстанса в него не встроен.
