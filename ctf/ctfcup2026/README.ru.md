# CTFCUP 2026, квалификация X Кубка CTF России

[English version](README.md)

Здесь лежат шесть райтапов по заданиям, сданным командой 31 октября 2026 года. Структуру взял из [Solar CTF](../Solar/README.ru.md). Основные тексты на английском, версии для чтения на русском имеют суффикс `.ru.md`.

Соревнование проходило на [CTFCUP](https://game.ctfcup.online/). Формат флага: `ctfcup{[A-Za-z0-9_]+}`.

| Задача | Баллы | Суть |
| --- | ---: | --- |
| [ker quest](misc/ker-quest/README.ru.md) | 400 | Многоступенчатые архивы, форензика, реверс и OSINT |
| [Traverse](reverse/traverse/README.ru.md) | 207 | Битстрим FPGA iCE40 и Python |
| [MeowSim: Schrodinger Edition](mobile/meowsim-schrodinger/README.ru.md) | 100 | Статический реверс Android и расшифровка |
| [MMM](reverse/mmm/README.ru.md) | 100 | Матрица в данных ELF |
| [Chik Chirik](crypto/chik-chirik/README.ru.md) | 229 | Аудиосимволы, Рид-Соломон, xorshift128 |
| [Ровный робот](blockchain/flygammon/README.ru.md) | 642 | Предсказание VRF и стратегия игры |

У каждой задачи есть описание `README.md`, подробный путь решения `solve.md` и русские версии этих файлов. Флаги скрыты как `ctfcup{...}`, как и в Solar. В тексте отделены проверенные шаги от того, что невозможно восстановить по сохранившимся материалам.
