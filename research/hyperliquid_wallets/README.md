# Hyperliquid — анализ закрытых исполнений публичных кошельков

**Состояние на 10.11.2026:** исходные данные показывают прибыльные частичные закрытия, но из них нельзя вывести полную доходность кошелька и воспроизводимый механизм с небольшим капиталом.

## Исследовательский вопрос

Если реальные трейдеры получают прибыль, можно ли восстановить, **когда они открывали позиции, сколько рисковали и за счёт чего заработали**? В отличие от публичных Binance Spot trades, Hyperliquid предоставляет fills по адресу кошелька.

## Что сделали

По публичному `POST https://api.hyperliquid.xyz/info` агент запрашивал `userFillsByTime`, `userFunding`, `clearinghouseState` для **двух публичных кошельков**. Задано окно `2026-11-03..2026-11-09 UTC`. Без авторизации и без ордеров.

- A, публичный псевдоним BobbyBigSize: **2000** сохранённых fills (из них **809 closing**), window из сохранённого payload лишь `2026-11-09T20:25:52Z..21:23:11Z`; **PARTIAL / UNVERIFIED**.
- B, второй исследуемый адрес: **2000** сохранённых closing fills лишь `2026-11-05T17:22:36Z..17:45:36Z`; **PARTIAL**.
- По неизменённым `raw_fills.json` получены `sum(closedPnl)-sum(fee)`: A **+85,032.079458 USDC**, B **+120,396.869096 USDC** на *сохранённых срезах*, НЕ чистая недельная прибыль аккаунтов.
- **Важная исправленная ошибка:** в первоначальном отчёте агент перепутал знак комиссии. `fee>0` — расход, `fee<0` — rebate. Нельзя складывать `closedPnl+fee`; нужно `closedPnl-fee`.
- Фрагменты закрытий относятся к крупным short позициям (особенно HYPE/ZEC, BTC/ETH); несколько fills на один `oid` — **не** независимые торговые циклы.
- Funding: ровно 500 записей/кошелёк, покрытие лишь частью недели; **не прибавляли** funding к total. Открытый unrealized PnL из одиночного снимка не включён.
- Была обнаружена замена ранее сохранённого `aggregates.json` после отчёта; для повторного аудита использовали только исходный `raw_fills.json` с проверенным SHA.

## Итог

Наличие прибыльных закрытий **не доказывает**, что это положительная воспроизводимая стратегия. История открытий до окна и убытков других периодов неполна; крупные leverage-позиции не эквивалентны капиталу $1 тыс.

## Методологическая ловушка

2 000 fills — лимит одного ответа API, а **не количество всех сделок недели**. При любой усечённости писать `PARTIAL`, не придумывать win rate и не считать отдельные fills 2000 самостоятельными сделками.
