> We lost the reactor's calibration profile after the cold-start test. The test readings and the receipt are still there. Can you recover the profile that was signed?

**Исходник:** `cold-echo.tar.gz`, 2271 байт, SHA-256 `a0776d87b60944a1e6d0919012dc4a759212f2d08c015c46d6036f34bc650877`.

## Решение

Архив содержит 42 измерения `P(u)P(u⁻¹)` неизвестного многочлена степени 42 над `F_p`, нормировку `P(1)=1`, одно прямое значение `P(89)` и подпись ECDSA P-256 под каноническим чеком, содержащим все коэффициенты.

Строим самосопряжённый многочлен `S(X)=P(X)X^42P(1/X)`: **42×43 линейная система** по модулю `p` и условие `S(1)=1` определяют все 85 коэффициентов. Факторизация даёт 84 корня, объединяем их в 42 пары `(r,r⁻¹)`. Из `2^42` вариантов выбираем подходящие посредством **meet-in-the-middle**. Получаем 243 кандидата; **ровно один** проходит ECDSA. Полученное подписанное сообщение используется для SHA-256-пада и XOR с маской флага.

Полное значение флага остаётся в частном архиве, в GitHub обозначено `gctf{...}`.
