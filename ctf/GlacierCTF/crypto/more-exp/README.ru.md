## Условие

FuzzyGmbH создала сервис шифрования. Его ещё не проверяли, поскольку расшифрование пока не поддерживается. Один из стажёров уже выразил сомнения, но к его мнению не прислушались. Оригинальный английский текст приведён в [README.md](README.md).

Сервис принимает выбранный открытый показатель и необязательное сообщение в JSON. Если сообщение не указано, шифруется флаг. Модуль RSA скрыт и генерируется заново для каждого соединения.

Цель: восстановить флаг без факторизации модуля. Сначала найдём модуль через НОД разностей для известных сообщений, затем восстановим флаг по двум шифротекстам с показателями 65537 и 65538. В первой попытке возник лишний множитель в НОД; после исправления скрипт сработал.
