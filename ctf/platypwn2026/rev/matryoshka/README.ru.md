# Matryoshka

[English](README.md) | [Полное решение](solve.ru.md)

**Категория:** Reverse engineering · **Сложность:** 1 · **Результат:** флаг принят платформой

Внешний ELF запускает вложенный `stage2` через `memfd_create`. Во внутренней программе проверяются четыре CRC32 от 4-байтных частей 16-байтного пароля. Обращение аффинных уравнений над GF(2) восстанавливает пароль, после чего программа выводит флаг.

**Пароль (hex):** `c667c58c3b02d6c91b8def4fdd1bc5f3`  
**Флаг:** `PP{th3r3_1s_4_b1n4ry_1n_my_b1n4ry?!}`
