# Bish Bash Bosh

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** misc
- **Сложность:** 1
- **Материалы:** `server.sh`, `Dockerfile`, `entrypoint.sh`, compose; exploit command in evidence
- **Флаги:** 1 принято (`PP{...}`)

Небольшое меню Bash просит число от 0 до 2 и показывает одно из трёх сообщений, но в арифметическую операцию передаётся пользовательский ввод.

**Причина:** Скрипт делает `read -r i`, затем `let i=$i-1` и лишь после этого проверяет диапазон перед `cat -- "${files[i]}"`. В арифметических выражениях Bash допускаются конструкции с индексами массивов и командной подстановкой. Такая подстановка может выполниться **до** проверки диапазона. В массиве даже есть `/flag/flag.txt` в начальном слоте, но простой выход за границы меню — не использованный путь.
