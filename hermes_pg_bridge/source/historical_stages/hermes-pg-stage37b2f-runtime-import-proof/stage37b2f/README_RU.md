# Stage 37B2F — независимое доказательство импорта плагина

**Цель:** доказать оценку *нового* ES-модуля внутри реального процесса MultiTool, не изменяя код оригинального кандидата 37B2C и не выдавая разрешения на запись.

## Ограничения

- Только временная замена **пути восьмого** плагина в `~/.config/gigatool/opencode.json`, неизменные опции (`dry_run=false`, `tick_ms=30000`, единственный `task_id`). Dispatch у задания выключен, а обе capabilities записи отсутствуют.
- Временный `.mjs` *переэкспортирует* код исходного кандидата неизменным и сохраняет при оценке модуля приватную квитанцию `{pid, start_ticks, candidate_sha, module_path, created_unix}` без тел запросов и секретов.
- Ни PostgreSQL-записи, ни SDK-вызовов, ни изменения systemd, MCP, туннеля, сроков разрешений. Для сравнения состояния применяется старый проверенный 37B2D read-only preflight.
- Наличие корректного маркера **с действующим PID MultiTool и совпадающим временем начала процесса** доказывает импорт модуля. Это **не доказывает**, что таймер `runTick` реально исполнился или что обработчик выполнил новое задание. Такие проверки требуют отдельного этапа.
- Не импортировать wrapper вручную для «проверки», не запускать `node wrapper.mjs`. Синтаксическую проверку `node --check` выполняет подготовка — она не создаёт доказательство.

## Шаги

1. При открытом MultiTool: `bash stage37b2f/460_install_prepare.sh`. Скрипт проверяет предыдущий 37B2D и создаёт бэкап и черновик; конфиг не меняет.
2. Полностью закрыть MultiTool, в обычном терминале: `bash /home/kali/hermes-pg-stage37b2f-runtime-import-proof/461_commit_when_closed.sh`. При STOP **не повторять**.
3. Открыть один MultiTool, затем: `bash /home/kali/hermes-pg-stage37b2f-runtime-import-proof/462_verify_after_reopen.sh`. Положительный результат: `STAGE37B2F_RUNTIME_WRAPPER_EVALUATED_IN_LIVE_MT`. Если `STOP_RUNTIME_IMPORT_NOT_INDEPENDENTLY_PROVEN`, это *не* означает, что plugin не запущен; дайте маркеры, не запускайте повторно.
4. **После положительной проверки или по согласованию на откат**: закрыть все MultiTool и выполнить `bash /home/kali/hermes-pg-stage37b2f-runtime-import-proof/463_restore_when_closed.sh`, затем открыть MultiTool. Это возвращает побайтово предыдущий конфиг с **37B2C** кандидатом (а не старый 34EB), без изменения данных.
5. `464_status_readonly.sh` — только чтение. Сохраняет журналы и оригинальный бэкап для аудита.

Если после временного переключения MultiTool не открывается: закрыть всё приложение и использовать `463_restore_when_closed.sh` без выполнения `462`. Скрипт допускает аварийный откат сразу после попытки commit, когда текущая конфигурация совпадает с одной из двух известных версий. Никогда не повторяйте одноразовые `commit` или `restore` при STOP.
