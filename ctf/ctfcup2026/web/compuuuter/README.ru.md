# compuuuter

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** web
- **Задача:** https://game.ctfcup.online/tasks/compuuuter
- **Файлы:** `compuuuter.zip` с сервисом на Flask
- **Флаг:** `ctfcup{...}` (скрыт)

Flask-сервис хранит числовые dataflow-графы и считает их по запросу. Скрытая операция `type = 1337` возвращает флаг как little-endian целое, и загрузка с вычислением отклоняют графы, где она встречается.

Ошибка это зазор между проверкой и использованием: `compute` вызывает `guard(nodes)`, затем строит словарь ссылок на те же изменяемые объекты узлов и позже читает `type` заново. `PATCH` переписывает узел на месте без проверки флага, а приложение работает в threaded-режиме, поэтому конкурентная правка превращает константу в `1337` уже после прошедшего guard.

Окно расширяется намеренно: в 64-битном CPython `hash(n)` равен `n mod (2^61 - 1)`, поэтому id, кратные этому модулю, коллизируют, и вставка тысяч таких ключей в словарь становится задержкой. В записанном прогоне использовались 6001 узел и задержка 0.3 секунды, попадание с первой попытки.

Солвер: `scripts/exploit_compuuuter.py`. Исходники сервиса: `assets/`. Сырой прогон: `evidence/compuuuter_run.log`.
