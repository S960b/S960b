# find me if you can — GlacierCTF 2026

[English version](README.md) · [Полный райтап](solve.ru.md)

**Категория:** OSINT · **Баллы:** 50 · **Статус:** решено, второй вариант флага принят платформой по подтверждению участника.

**Задание:** по фотографии `2024.JPG` и маршруту **GVA → VIE** определить рейс, ATC-позывной и координаты самолёта.

## Правильный флаг

```text
gctf{OS572_AUA57M_47.75_12.35}
```

**Первый вариант** `gctf{OS572_AUA57M_47.75_12.36}` **не прошёл**. **Второй**, с долготой `12.35`, **был принят**. Номер рейса OS572, ATC callsign AUA57M и широта 47.75 в обоих вариантах одинаковые.

В исходном OSINT-исследовании рассматривались Austrian Airlines Embraer E195, расписания GVA–VIE за 2024 год и ориентиры в Альпах (район Wilder Kaiser / Ашау-им-Кимгау). Эти детали оставлены как история поиска; точная принятая строка известна из твоего подтверждения.

[Подробный ход решения](solve.ru.md) включает отброшенные гипотезы, оба кандидата и причину изменения координаты.
