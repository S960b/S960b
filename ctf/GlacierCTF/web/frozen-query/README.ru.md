# Frozen Query — GlacierCTF 2026

[English version](README.md) · [Технический райтап](solve.ru.md)

**Категория:** web · **Баллы:** 50 · **Статус:** решено, флаг принят платформой (по списку решённых задач участника).

Восстановленная техническая цепочка: **двойной gzip**, обход поверхностной проверки WAF и чтение **кэшированного ответа аудитора** для закрытого бюллетеня summit. Ключ кэша не учитывал авторизацию, а включал только путь, нормализованный Content-Type, Accept и канонический JSON запроса.

В доступных старых диалогах остался статус успешной проверки, но не исходный payload/ответ. Поэтому техническая реконструкция основана на **отдельно опубликованном разборе другого участника**, с указанием источника: [D23R / Frozen Query](https://dua2z3rr.github.io/posts/Frozen-Query-Walkthrough/). Это не выдаётся за точную историческую трассу пользователя. Полный принятый флаг из доступных записей не извлечён и не придуман.
