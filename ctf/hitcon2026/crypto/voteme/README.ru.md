- **Описание (официальное):** "Vote for me, myself and I."

Цепочка из шести независимых крипто-слабостей в одном сервисе голосования. В хендауте
Ruby-сервис (`record.rb` пишет PCAP), circom-схема с PLONK-ключом доказательства и
перехваченный трафик. Атака:

1. 2-адический ECDH: `Curve::ORDER` делится на 2^16, и каждый ServerKeyExchange
   утекает младшие 16 бит приватного скаляра.
2. Ruby `Random.new` (MT19937): все ECDH-скаляры из одного генератора, младшие биты
   дают линейную систему над GF(2), финальный TLS-скаляр предсказывается.
3. TLS AES-256-GCM расшифровывается восстановленным premaster; в открытом виде -
   JSON `/votes` с 1000 PLONK-бюллетеней.
4. Каждый бюллетень утекает `Math.random()` через уязвимость `@lukeed/uuid` v2;
   линейная алгебра восстанавливает состояние xorshift128+ с несколькими свободными
   битами, следующий рандом предсказуем.
5. PLONK blinding-скаляры тоже из `Math.random()`; пересчёт обязательства `A` для
   голоса в {0,1,2} опознаёт голос каждого бюллетеня.
6. Первые 420 голосов (70 байт флага) декодируются из троичной записи в ASCII.
