# Flacksafety (fullpwn, частичное решение)

[English](README.md) | [Полное техническое расследование](solve.ru.md)

**Статус:** governance-флаг получен и принят; **5 из 6** backup tiers отмечены как Destroyed. `Old Rclone Remote` сохранился, второй флаг **не получен**. Полный путь решения и отрицательные эксперименты описаны отдельно.

**Точка входа:** Argon2id в `shadow.txt` → SSH employee. Далее `/etc/resticprofile/profiles.yaml` с правами `rw-rw-rw-` и root-задание `supercronic` каждые 60 секунд позволили выполнить `run-before` от root. Из окружения получены доступы к restic, S3 и rclone.

**Главная исследовательская часть:** rclone v1.74.3 `serve restic --private-repos` с SFTP backend. Path traversal через `../` доказан для GET/POST/DELETE файлов, включая чтение `/entrypoint.sh`. Но листинг чужого дерева скрывается из-за несовпадения нормализованных и сырых путей. `has_files` шестого уровня требует удалить абсолютно все файлы; без списка имён и отдельного legacy-пароля это сделать не удалось.

**Материалы:** `shadow.txt` из раздатки и технические журналы с проверенными HTTP-кодами, командами, исходником чекера и конфигурацией сервера. Полные флаги/адреса/ключи скрыты.
