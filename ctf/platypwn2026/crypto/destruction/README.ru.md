# DEStruction

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** Platypwn 2026
- **Категория:** crypto
- **Сложность:** 2
- **Материалы:** `server.py`, `encryption.py`, Dockerfile, compose; submission command records
- **Флаги:** 2 принято, полные строки скрыты (`PP{...}`)

Самодельный GCM на 3DES с блоком 64 бита и тегом аутентификации всего в два байта. В сервисе две отдельные проверки для двух флагов.

**Суть:** В `DES3_GCM` используется `H=DES3_K(0^64)`, собственный `GHASH(..., blen=64)` и `tag=(GHASH(H, AD, ciphertext) XOR E_K(Y0))[:2]`. Оракул шифрования принимает выбранный 12-байтный текст, но запрещает `give me flag`. Длина AD управляется клиентом; содержимое его последних байтов генерирует сервер. Расшифровка принимает произвольные nonce, ciphertext, AD и 16-битный тег. Лимит составляет 168 запросов.

Подробности — в [решении](solve.ru.md).


## Оригинальный решающий скрипт

Найден оригинальный и проверенный на живом инстансе Python-солвер из предыдущего диалога. Он получает один шифртекст с большим AD, по 32 специальным вариантам восстанавливает 64-битный ключ GHASH над GF(2) и решает обе проверки. Пользователь подтвердил оба флага примерно за 80 из 168 запросов.

```bash
python3 scripts/destruction_full_solve.py <host> <port>
```

Код: [scripts/destruction_full_solve.py](scripts/destruction_full_solve.py). Параметры и проверки находятся в файле, адрес инстанса в него не встроен.
