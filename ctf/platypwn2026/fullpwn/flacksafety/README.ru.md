# Flacksafety

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** fullpwn
- **Сложность:** 3
- **Материалы:** `shadow.txt`, agent bridge governance investigation and later incomplete stage-six audit
- **Флаги:** 1 принято (`PP{...}`)

Многоэтапная задача про резервные копии и управление. Здесь описан только подтверждённый governance-флаг; старый репозиторий резервных копий остался незакрытым.

**Главная ошибка:** В раздатке только `shadow.txt` с Argon2id-хэшем; по отчёту пароль employee был восстановлен как `iloveme`. После входа обнаружен governance-конфиг профилей с правами `rw-rw-rw-` и хуком `run-before`, который выполняется через supercronic. Пользователь, контролирующий такой файл, может повлиять на команду привилегированного задания. Агент сообщил о выполнении 5/6 этапов и принятом governance-флаге; шестой этап зависел от `LEGACY_REST_PASSWORD` для старого репозитория rclone/restic и не был завершён.

Подробнее — в [решении](solve.ru.md).
