# Frozen Query — GlacierCTF 2026

[English version](README.md) · [Подробный райтап](solve.ru.md)

**Автор:** EmberZero · **Категория:** web / http / cache / rfc10008 · **Баллы:** 50

**Статус:** решено — флаг принят платформой (подтверждение участника).

**Адрес:** https://frozen-query.web.glacierctf.com/

Glacier Avalanche Service использует HTTP-метод `QUERY` из RFC 10008. Закрытый бюллетень `summit` с флагом должен быть доступен только аудитору.

Ошибки две: **WAF проверяет лишь один слой сжатия**, а **кэш выдаёт привилегированный ответ без учёта авторизации в ключе**. Отправляем `Content-Encoding: gzip, gzip` и дважды сжатый JSON. WAF видит бинарные данные и не обнаруживает `summit`/ `flag`; обработчик полностью распаковывает запрос и вычисляет идентичный ключ кэша аудитора. Аудитор опрашивает сервис каждые пять секунд, так что его ответ доступен как `X-Cache: HIT`.
