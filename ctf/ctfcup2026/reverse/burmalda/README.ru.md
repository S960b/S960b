# Burmalda

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** reverse / web (Godot HTML5)
- **Задача:** https://game.ctfcup.online/tasks/burmalda
- **Файлы:** `Burmalda.pck` (43 760 байт), скачан с инстанса
- **Флаг:** `ctfcup{...}` (скрыт)

Инстанс отдаёт игру-рулетку на Godot 4.4.1, экспортированную в HTML5. Поскольку вся игра работает в браузере, пакет ресурсов и скомпилированные скрипты достаются каждому игроку.

`Burmalda.pck` начинается с `GDPC` и содержит 18 записей, среди них `main.gdc`. Восстановление проекта через GDRE Tools (`--headless --recover`) даёт `main.gd`, где `_decode_flag()` собирает флаг из массива `_EF` на 151 байт с помощью 32-битной ЛКГ: состояние стартует с `_SA ^ _SB` (`0xCAFEBABE ^ 0x13371337`), обновляется как `1664525 * state + 1013904223`, байт ключа это `(state >> 13) & 0xff`, а каждый выходной байт равен `((_EF[i] ^ key) - i) & 0xff`.

`scripts/decode_flag.py` воспроизводит процедуру. Пакет с живого инстанса побайтово совпадает с разобранным, поэтому декодированная строка это флаг того деплоя.
