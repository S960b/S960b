# mircosoft — GlacierCTF 2026

[English version](README.md) · [Подробный технический райтап](solve.ru.md)

**Категория:** rev / Windows · **Баллы:** 50 · **Статус:** решено, флаг принят платформой (подтверждение участника).

В задании три исходных файла: защищённый Windows `mircosoft.exe`, привязанная к оборудованию лицензия `license.bin` и **дамп памяти компьютера администратора** `admin_machine.dmp`.

Реальный путь из предыдущего диалога: распаковка вложенного PE, извлечение пяти аппаратных идентификаторов из MiniDump, воспроизведение MAC/контрольной суммы лицензии, получение ключа и расшифровка лицензии собственным TEA-подобным алгоритмом.

**Принятый флаг:** `gctf{...}` (в публичном GitHub замаскирован).

Оригинальный `mircosoft (1).tar.gz` проверен: контрольные суммы всех трёх файлов совпадают. Мы независимо извлекли **семь областей памяти** из MiniDump и сверили их со смещениями сохранённого солвера.
