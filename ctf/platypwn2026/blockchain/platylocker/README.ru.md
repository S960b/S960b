# PlatyLocker

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** blockchain
- **Сложность:** 1
- **Исходники:** `Chal.sol`, `Setup.sol`, `locker_operator.py`
- **Флаги:** 1 принято (`PP{...}`)

Контракт-шифровальщик хранит приватный показатель RSA в поле Solidity `private`, ошибочно принимая модификатор видимости за конфиденциальность.

**Причина:** `initialize` сохраняет модуль RSA, публичный и **секретный** показатели и шифртекст прямо в storage. Оператор генерирует 1024-битную RSA-пару и 32-байтный AES-ключ, шифрует AES-ключ как `pow(m,e,n)` и передаёт `d` в контракт. `private` запрещает прямой вызов геттера из другого Solidity-контракта, но не чтение storage через RPC. Длинные `bytes` размещаются по хэшируемым адресам слотов.
