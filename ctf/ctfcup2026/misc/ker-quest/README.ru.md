# ker quest

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** CTFCUP 2026, квалификация 31 октября
- **Баллы:** 400
- **Задание:** https://game.ctfcup.online/tasks/ker_quest
- **Направление:** misc, криптография, форензика, реверс, OSINT
- **Флаг:** `ctfcup{...}` (скрыт)

Задача представляет собой цепочку разнородных этапов. Сначала требуется вспомнить год первого CTF автора. Затем идут ZIP-архивы с паролями, повреждённый PNG, пазл, MIPS-программа, звуковая запись, ELF, PCAP, OSINT, JavaScript и ROT13.

[solve.ru.md](solve.ru.md) объясняет не только какие пароли получились, но и зачем каждый следующий шаг был нужен. Часть вспомогательных файлов сохранилась в исследовательском архиве `ker_quest_compact.zip`. Последние этапы восстановлены по журналу решения.
