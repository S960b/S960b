# Not My Type

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** blockchain
- **Сложность:** 1
- **Исходники:** `Chal.sol`, `Setup.sol`, `payment_backend.py`
- **Флаги:** 1 принято (`PP{...}`)

Платёжный сервис принимает сумму в ETH как строку, а бэкенд проверяет и списывает её в разных числовых представлениях.

**Причина:** `check_transfer(balance, amount)` превращает строку во `float`, требует значение больше нуля, затем делает `if balance < int(value)`. Для числа между 0 и 1 `int(value)` равно нулю. Даже пустой счёт проходит проверку. Но при расчёте бэкенд передаёт `int(value * 10**18)`, уже без усечения до целых ETH. В Solidity внутренние балансы типа `int256`, а `settle` не проверяет достаточность средств повторно.
