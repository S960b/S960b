# Codex (Святой Кодекс)

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 115
- **Категория:** web
- **Задача:** https://game.ctfcup.online/tasks/codex
- **Файлы:** `codex.zip` с исходниками сервера, бота и фронтенда
- **Флаг:** `ctfcup{...}` (скрыт)

Приложение для чтения Библии с заметками и ботом-администратором. Бот кладёт флаг приватной заметкой на странице `matthew.7`, со `scope`, равным своему `BOT_UUID`. В этой версии это `process.env.BOT_UUID || 'cccccccc-cccc-4ccc-8ccc-cccccccccccc'`, а деплой переопределяет только флаг, поэтому работает значение по умолчанию.

Решение это три запроса: прочитать scope (пусто), дёрнуть `/api/visit`, чтобы бот создал заметку, прочитать scope снова. Суффикс флага выдаётся под конкретный деплой, поэтому его надо читать с живого инстанса.

Автоматизация: `scripts/solve_codex.py <адрес-инстанса>`. Вариант Revenge генерирует UUID на каждый процесс и закрывает заметки администратора отдельной cookie, поэтому тот же скрипт там возвращает пусто.
