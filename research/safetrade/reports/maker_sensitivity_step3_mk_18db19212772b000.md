# Шаг 3 — сценарный sensitivity-анализ PRLUSDT и QUANTUSUSDT (2026-10-05)

Отдельный исследовательский модуль; основной opportunity v3 НЕ изменён.
Гипотезы взаимоисключающие, одна сделка в одном сценарии имеет ОДНО
направление: H1 public side=taker side; H2 public side=maker side (инверсия).

## Правила модели (по ТЗ)
- Виртуальный капитал 100 USDT (50% USDT + 50% base по первой средней цене),
  без займа и отрицательных остатков.
- PRL: только присоединение к лучшему bid/ask (свободного тика нет).
  QUANTUS: отдельно join BBO и improve на 1 тик, только когда не пересекает
  противоположную сторону.
- Размер заявки 5/10/25 USDT. Очередь впереди 0x/1x/2x видимого объёма
  уровня. FIFO, частичные исполнения, остаток заявки и позиции переносятся.
  Уменьшение уровня без подтверждённой сделки не исполняет нашу заявку.
- Задержка активации 0/1/5 с; решение только по данным, известным к моменту;
  стакан старше 30с -> unobserved (не заменяется будущим).
- Комиссия 0,1% на каждое исполнение. Force-exit taker по оставшейся
  противоположной стороне при удержании >30 мин и в конце окна; недостающая
  глубина -> unrealized.
- Окно: 44.0003h (start 2026-10-03T18:41:46Z → cutoff 2026-10-05T14:41:46Z).
