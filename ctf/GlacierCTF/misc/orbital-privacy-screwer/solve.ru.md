# Orbital Privacy Screwer — Морзе, спрятанная во времени SSE

[English version](solve.md)

## 1. Спутниковый интерфейс был отвлекающим

Лаунчер `nc challs.glacierctf.com 13381` выдавал персональный веб-инстанс с временем жизни около **600 секунд**. Страница изображала дашборд захвата спутниковых целей.

Фронтенд открывал поток `EventSource`:

```text
GET /api/acquire?q=<строка>&reqId=<id>&sessionId=<id>
```

Обычная сессия состояла из `cycle_start`, **67 событий `step`**, затем `complete`. Длительность около **7.936 секунды**. Поля `phase`, `pct`, `carrier`, `sector_code`, `hash`, `telemetry_variance` выглядели как служебная телеметрия.

Однако исходник `src/server.py` прямо описывает `Morse steganographic encoder with flag count verification`. В нём заданы:

```python
DOT_DURATION_MS = 67
DASH_DURATION_MS = 133
SEPARATOR_DURATION_MS = 200
TARGET_DOTS = 30
TARGET_DASHES = 22
TARGET_SEPARATORS = 15
EXPECTED_TOTAL_EVENTS = 67
EXPECTED_DURATION_MS = 7936
```

Загружаемый флаг переводится в верхний регистр; файл `flag.txt` в архиве организаторов — заглушка.

## 2. Как именно передавался секрет

Функция `load_and_verify_gctf()` читает секрет, переводит его в uppercase и преобразует каждый символ таблицей `MORSE_CODE`. `build_morse_event_sequence()` создаёт последовательность точек, тире и разделителей с соответствующими временами.

В `handle_acquire_stream()` сервер **сначала отправляет событие**, а затем спит указанное время:

```python
for event_data in PRECOMPUTED_TRANSMISSION:
    send_sse_message(payload)
    precise_sleep(event_data["duration_ms"] / 1000.0)
```

Длительность не передаётся в JSON. Символ кодируется **задержкой до следующего `step`**, а для последнего — задержкой до `complete`.

Поле `carrier` показывает только «точка/тире» против разделителя, но не различает две длины сигнала. Для обычного запроса сервер вычисляет детерминированную диагностику через SHA-256 нормализованной строки:

```python
normalized = " ".join(query.strip().lower().split())
digest = sha256(normalized.encode()).hexdigest().upper()
short_hash = digest[:8]
sector_code = f"SEC-{int(digest[8:12],16)%99+1:02d}"
variance = int(digest[12:14],16)/255*0.08 + 0.01
```

Команды `status/help/ping/assets/sensors/grid/ephemeris` были отвлечением от основного канала.

## 3. Поиски до чтения исходника

В предыдущем сеансе проверили traversal в статике, командные и SQL-подобные инъекции в `q`, шаблонные строки, скрытые параметры API, IDOR через `sessionId`, подмену заголовков, гонки, коды секторов, фрагменты картинки `background-image.png`, LSB и данные PNG после IEND. Ни один вариант не дал флага.

Поведение `/api/acquire` оказалось стандартным: пустая строка отвергается, длина `q` ограничена 128 символами, `POST /api/cancel` прерывает сеанс, а параллельные запросы изолированы. Стало ясно, что задача не в обходе авторизации или чтении файлов, а в **расшифровке преднамеренного побочного канала**.

## 4. Шесть захватов времени

Финальный исторический скрипт `morse4.py` отправлял шесть отдельных HTTPS-запросов с разными `reqId/sessionId` и фиксировал `time.perf_counter()` при каждом событии `step` и `complete`.

Это **68 меток времени и 67 интервалов**. Последний интервал `step → complete` нельзя потерять: он содержит последний символ Морзе.

Для каждой позиции бралась медиана шести измерений. Захваты с неестественными 0/484.8 мс отвергались — прокси иногда склеивал события. Все шесть окончательных прогонов содержали по 67 интервалов, их общие медианы лежали в диапазоне 131.6–132.7 мс.

Классификация:

| Интервал | Символ |
| --- | --- |
| меньше 100 мс | точка `.` |
| от 100 до 170 мс | тире `-` |
| больше 170 мс | разделитель букв |

Оригинальные 67 измеренных медиан включены в [scripts/verify_decode.py](scripts/verify_decode.py). В [scripts/capture_morse.py](scripts/capture_morse.py) оставлен тот же алгоритм с аргументом URL вместо частного файла `/tmp/gigatool/url.txt`.

## 5. Восстановление текста

После классификации:

```text
--. -.-. - ..-. ----- -... .-.. .. ...- - -.. .-. ...-- ... --... -
```

Обратная таблица Морзе даёт:

```text
GCTF0BLIVTDR3S7T
```

Контрольные показатели:

| Показатель | Исходник | Измерение |
| --- | ---: | ---: |
| Точки | 30 | 30 |
| Тире | 22 | 22 |
| Разделители | 15 | 15 |
| Шаги | 67 | 67 |
| Теоретическая сумма | 7936 мс | 7936 мс после обратной кодировки |

Файл `verify_decode.py` перекодировал полученный текст и сравнил **все 67 позиций** с медианами: расхождений по категориям нет. Суммарная длительность измеренных медиан в сохранённой проверке около **7947 мс** из-за джиттера сети.

Важно: в потоке находилась **16-символьная строка без скобок**, а не готовый флаг формата `gctf{...}`. Для сдачи первые четыре символа `GCTF` используются как префикс, остальная часть приводится к нижнему регистру и помещается в фигурные скобки. Пользователь **проверил этот результат на платформе и подтвердил принятие**.

Полный флаг в публичном репозитории по принятой политике маскируем как `gctf{...}`, однако исходный текст сигнала оставляем, чтобы метод оставался воспроизводимым.

## 6. Ограничения доказательств

Архив `glacierctf_orbital-privacy-screwer_materials.zip` содержит оригинальный архив задания, `server.py`, скрипты, сохранённые выдержки из консольных логов, тесты API и результаты декодирования.

В старом отчёте упоминался другой, более длинный кандидат; **он не соответствует этим 67 SSE-интервалам**, поэтому не рассматривается как вывод живого сервиса. Пользователь позднее подтвердил принятие короткого флага.

Отдельно обнаружено несовпадение поля `pct`: в сохранённом исходнике оно зависит от накопленной длительности, а в живом инстансе было равномерным. Возможная причина — другая версия развёрнутого кода; её исходник не сохранился. Это не изменило тайминги Морзе.

Сырые сетевые пакеты, серверные логи и скриншот принятия флага не сохранены. Консольные результаты перенесены в `evidence/*.txt`; принятие платформой зафиксировано со слов участника. Во время написания райтапа сервис не запускался.

## 7. Выводы

- SSE может передавать секреты **через время**, даже когда JSON выглядит как обычная телеметрия.
- Нужно измерять 67 промежутков, включая последний `step → complete`.
- Медиана нескольких измерений убирает джиттер и склейку кадров прокси.
- Результат подтверждается и числом символов, и таймингами из исходного кода.
- Сырой текст передачи и формат принятого флага следует различать.
