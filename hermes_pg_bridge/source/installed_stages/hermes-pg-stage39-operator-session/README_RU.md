# Stage 39 — управляемый рабочий сеанс (v1)

**Назначение:** заменить разовые допуски 38/38A на один ограниченный операторский сеанс с автоматическим продлением уже существующих разрешений. Это *не* постоянно открытая запись.

## Что делает

- Привязан к `task_b6c26aa18220412bafdbf32393f16568`, к полному SHA восьмиплагинового `opencode.json` и к конкретному файлу managed-плагина.
- Оператор один раз запускает `390_install_and_open.sh`. Он проверяет пакет, выполняет офлайн-тесты, устанавливает user-systemd таймер на 60 секунд, затем открывает `permit` для ChatGPT и отдельный `gate` для Hermes.
- Начальный permit действует 60 минут, но продлевается **только когда прежний ещё действителен** и проверена неизменность конфига. Gate с лимитом Stage37A 20 минут освежается каждые 5 минут таймером.
- Абсолютный предел сеанса: **6 часов**. После него оба разрешения автоматически отзываются, даже если идут долгие задачи. Требуется новое осознанное открытие сеанса. Внутри одного окна можно отправлять последовательные поручения в закреплённый диалог.
- Если файлы разрешений исчезли, watchdog их отозвал, изменился SHA конфигурации, произошёл рестарт машины или сломался keeper — **самовосстановления доступа нет**. Для повторного открытия требуется оператор.
- Установка/таймер **не меняют PostgreSQL, MCP, туннель, исходный плагин, config или dispatch**. Диспетчер включается отдельно через `pg`, после чего ChatGPT отправляет задачи.
- Аварийный стоп: `393_close_session.sh` (или независимый `371_emergency_revoke.sh`, если Stage39 недоступен).

## Однократная установка и открытие

Скопировать ZIP в `/home/kali/Downloads`, проверить SHA256 ZIP по поручению ChatGPT, распаковать в `mktemp -d` и запустить `bash <распаковано>/stage39/390_install_and_open.sh`. Запускать **дочерней оболочкой**, не `source`.

## Безопасность и границы

- No authentication в UI ChatGPT означает отсутствие OAuth, но MCP защищён своим `X-Bridge-Local-Key` и туннелем; Stage39 **не меняет** эти механизмы.
- CLI gate исторически проверяет общую локальную фразу, а не task_id: ограничение конкретного диалога обеспечивают `opencode.json`, managed SQL-policy и MCP-permit. Это не равнозначно изоляции от полностью скомпрометированного локального аккаунта kali.
- Секреты не записываются в маркеры; сама gate-фраза уже зафиксирована в существующем локальном CLI.
- Таймер не зависит от Taskboard `8789` и не обходит её авторизацию `401`.
- Срок 6 часов — явный компромисс: длиннее коротких 20-минутных допусков, но с безусловной границей. Бесконечных продлений нет.
- Пакет **не исправляет сам по себе** окна SQL claim / выдачи lease. Он не удаляет журналы `claim-intent` и не переисполняет SDK автоматически.
- Если Stage39 выдаст STOP, **не повторяйте старые Stage38/36B** и не создавайте файлы вручную.

## После успешного открытия

Верните маркеры `STAGE39_*` и попросите ChatGPT через `pg` проверить `write_permit_present=true`, затем отправить назначенную пользователем задачу. Не создавайте диалоги или сообщения со стороны агента.
