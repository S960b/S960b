# Ровный робот (flygammon)

[English](README.md) | [Подробное решение](solve.ru.md)

- **Соревнование:** CTFCUP 2026
- **Баллы:** 642
- **Категория:** crypto / blockchain
- **Задание:** https://game.ctfcup.online/tasks/flygammon
- **Архив:** `flygammon-handout.tgz`
- **Флаг:** `ctfcup{...}` (скрыт)

Нужно выиграть 15 партий подряд у автоматического соперника в блокчейн-версии нард. Уязвимость заключалась в предсказуемом VRF: секретный показатель восстанавливался алгоритмом Полига-Хеллмана из-за гладкого порядка группы. Затем можно было заранее выбрать удобные ID партий, смоделировать решения бота и провести транзакции. В наших отчётах подтверждена серия до 11 побед, а в командных сдачах задача числится принятой.
