# Ron's Revenge

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** Platypwn 2026
- **Категория:** crypto
- **Сложность:** 2
- **Материалы:** `server.py`; exploit process check/log path (actual exploit absent)
- **Флаги:** 1 принято, полные строки скрыты (`PP{...}`)

Потоковый шифр на основе RC4 с состоянием 2048 элементов и выбираемым клиентом IV.

**Суть:** Сервис создаёт долгосрочный ключ из восьми слов, добавляет перед ним три слова IV от клиента и шифрует один и тот же флаг. В состоянии 2048 значений, каждый выход RC4 занимает 11 бит и упаковывается в байты. Из известного префикса `PP{` можно получать начальные биты гаммы; смещения KSA остаются статистически уязвимыми даже при большом состоянии.

Подробности — в [решении](solve.ru.md).


## Оригинальный решающий скрипт

Найден оригинальный FMS-солвер: KSA RC4-2048, голосование по слабым IV, извлечение 11-битного слова из известного двухсимвольного префикса, проверка полного ключа и локальный --selftest. В публичной версии тестовый искусственный текст заменён маркером, не похожим на реальный флаг.

```bash
python3 scripts/ronsrevenge_exploit.py <host> <port>
```

Код: [scripts/ronsrevenge_exploit.py](scripts/ronsrevenge_exploit.py). Параметры и проверки находятся в файле, адрес инстанса в него не встроен.
