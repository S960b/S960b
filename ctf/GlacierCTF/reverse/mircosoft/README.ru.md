# mircosoft — GlacierCTF 2026

[English version](README.md) · [Полный русский райтап](solve.ru.md) · [Объединённый EN/RU](WRITEUP_RU_EN.md)

**Категория:** rev / Windows · **Баллы:** 50 · **Статус:** решено, **полностью воспроизведено на оригинальном архиве**.

Защищённый PE-загрузчик скрывает четыре DRM-ключа. Из выданного MiniDump восстанавливаются аппаратные идентификаторы администратора; затем проверяется MAC лицензии и расшифровывается 64-байтовая полезная нагрузка.

**Недостающий этап распаковки PE теперь найден и проверен.** В исходном диалоге подготовлен [`scripts/unpack.py`](scripts/unpack.py), который восстанавливает вложенный исполняемый файл непосредственно из оригинального `mircosoft.exe`.

Повторный прогон подтвердил:

```text
unpacked_pe.bin: 18432 байта
SHA256: 9d5df8e2717f29b5ee8af7a0b2c423de754aac7676e65c4429bc74361f191d80
Вычисленный MAC: 8305d5d5c5316f76bd27ddbbc5221f56
MAC из лицензии: 8305d5d5c5316f76bd27ddbbc5221f56
Флаг: gctf{...} [принят, скрыт в публичном тексте]
```

## Воспроизведение одной командой

```sh
python3 scripts/reproduce.py /path/to/mircosoft.tar.gz
```

Нужны только Python 3.10+ и оригинальный архив. Wine, Windows и сторонние библиотеки **не требуются**.

Скрипт последовательно запускает [распаковщик](scripts/unpack.py), [экстрактор MiniDump](scripts/extract_minidump.py) и [финальный дешифратор](scripts/solve.py), сверяет SHA-256 и MAC. Все этапы, включая дизассемблирование загрузчика, перестановку 72 блоков, XTEA и сбор fingerprint, подробно описаны в [solve.ru.md](solve.ru.md).

Дополнительно: [доказательства](evidence/README.md), [инструкция по скриптам](scripts/README.md). Полный принятый флаг намеренно скрыт в публичной версии.
