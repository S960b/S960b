## Идея

Схема gnark v0.16.4 требует доказать уравнение для `Q = [s]P` на BLS12-381 G1. Для честного умножения это невозможно, но классическая реализация GLV scalar multiplication использует хинты и неполные формулы сложения. Подмена корректно ограниченного разложения скаляра позволяет получить в последнем окне исключительный случай **`0/0`** и выбрать произвольный наклон хорды. В результате на выходе появляется точка **вне кривой**, удовлетворяющая проверке задачи.

Рабочее решение находит короткий вектор решётки GLV, решает многочлен степени 12 для свободного наклона, создаёт доказательство с исходным `pk.hex` и отправляет его сервису после успешной проверки через `vk.hex`.
