# Traverse

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 207
- **Категория:** реверс-инжиниринг / FPGA
- **Задача:** https://game.ctfcup.online/tasks/traverse
- **Файлы:** `traverse.zip`, внутри `traverse.bin` и `run.py`
- **Флаг:** `ctfcup{...}` (скрыт)

В архиве лежала конфигурация iCE40 HX1K, а не исполняемый файл для процессора. Распаковка через IceStorm и конвертация в нетлист дают 693 LUT и 69 триггеров без блочной RAM, а `icepack` воспроизводит исходный битстрим побайтово.

На любую строку схема отвечает одним байтом и всегда `f` (`0x66`). Настоящий результат появляется только на переводе строки и зависит от восьмибитного регистра состояния, который обновляется на каждом символе. Модель комбинационной логики на Python, сверенная с Icarus на 2768 тактах, и обход в ширину по 139 достижимым состояниям дают единственное принимающее состояние (`0x7f`), а путь до него и есть флаг. Прогон через исходный `run.py` возвращает `s` (`0x73`), любая мутация возвращает `f`.

Решатель лежит в `scripts/solve_traverse.py`.
