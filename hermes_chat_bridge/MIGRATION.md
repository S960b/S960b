# Совместимость путей

При выделении Hermes Chat Bridge в самостоятельный каталог исторические исходники старой реализации перенесены без изменения файлов:

```text
hermes_chat_bridge/
  README.md
  CURRENT_STATE.md
  readmefirst.txt
  prompt_recover_for_AI.txt
  MIGRATION.md
  legacy/              — ранний код, тесты и отчёты

research/hermes_chat_bridge -> ../hermes_chat_bridge/legacy
```

Последняя строка — символическая ссылка Git для совместимости со старыми относительными путями. На Linux она разрешает обращения к историческим файлам, в том числе `bridge_server.py`. Это важно, поскольку транспортный компонент может использоваться установленной локальной системой.

Символическая ссылка не означает, что старые команды `bridge_cli` и SQLite-очередь являются актуальным протоколом. Современный обмен использует Git-диалоги, authority и MT Inbox.

Перенос касается **только файлов Git**. Он не запускает и не останавливает службы, не перемещает локальные БД и не изменяет текущие сессии. Перед обновлением рабочего checkout следует проверить привязки служб, реальную структуру каталогов и работу символических ссылок.
