# Chik Chirik

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** CTFCUP 2026
- **Баллы:** 229
- **Категория:** crypto / misc / audio
- **Задание:** https://game.ctfcup.online/tasks/chik-chirik
- **Файл:** `capture.wav`
- **Флаг:** `ctfcup{...}` (скрыт)

Задача построена на аудиопередатчике с небольшой символьной азбукой. После демодуляции нужно выполнить декодирование Рида-Соломона RS(7,3), восстановить 128-битное состояние генератора xorshift128 из линейных ограничений над GF(2), снять преобразование и проверить CRC32. Подробные этапы в [solve.ru.md](solve.ru.md).
