# Uroki (Электронный журнал)

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 394
- **Категория:** web
- **Задача:** https://game.ctfcup.online/tasks/uroki
- **Файлы:** `uroki.zip` с приложением на Flask и конфигом supervisor
- **Флаг:** `ctfcup{...}` (скрыт)

Школьный журнал: создать урок, приложить файл, скачать его. Две ошибки складываются в цепочку.

`storage.clean_name` отбраковывает `..`, обратный слеш и управляющие символы, но не ведущий слеш, а `os.path.join` отбрасывает каталог загрузок для абсолютного имени, поэтому загрузка файла с именем `/data/uroki.db` подменяет базу приложения. Маршрут скачивания передаёт `file_path` из этой базы прямо в `send_file`, что даёт произвольное чтение файлов.

Для флага этого мало: `entrypoint.sh` делает `chown app:app /flag.txt; chmod 0000 /flag.txt`, поэтому `send_file` падает и эндпоинт отвечает 500. Владелец всё ещё может `chmod`, значит второй шаг требует исполнения кода от `app`. Воркер Celery работает с `-B` и держит расписание в базе `shelve` по пути `/data/celerybeat-schedule`, а создание любого урока вызывает `supervisorctl restart celery`. Положенный туда pickle-payload и создание урока дают исполнение, payload делает chmod флага, и обычный маршрут скачивания его отдаёт.

`scripts/uroki_exploit.py <url>` проходит всю цепочку; вывод в `evidence/run.log`.
