# My Own FS

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** misc / форензика файловых систем
- **Задача:** https://game.ctfcup.online/tasks/my-own-fs
- **Файлы:** `my-own-fs.zip` с ФС на Rust (FUSE) и `disk.img`
- **Флаг:** `ctfcup{...}` (скрыт)

Самодельная ФС с таблицей по байту на инод (`[0, N)`, `N = размер / 1338`) и инодами по 1337 байт, связанными указателем `next`. Головной инод несёт 51-байтовую шапку с типом, правами, uid, gid, размером и временами; у продолжений только `next` и тип.

`unlink` сбрасывает байт в таблице инодов и убирает запись каталога, но данные не затирает, а `shuffle` переставляет только физические слоты. Живое дерево это пустая приманка, поэтому решение в том, чтобы обойти все иноды, пройти по цепочкам и проверить содержимое на сигнатуру. Так восстанавливается удалённый PNG на 214 153 байта из инода 2979 (161 инод, 900 на 160), внутри которого флаг.

`scripts/carve_png.py disk.img carved.png` выполняет скан и сохраняет изображение.
