# Horse Racing

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** web
- **Сложность:** 1
- **Материалы:** Rust/Axum `src/main.rs`, `Cargo.toml`, HTML-клиент, сохранённый отчёт об успешном решении
- **Флаги:** 1 принято (`PP{...}`)

В приложении скачек игрок начинает с 10 очков и получает VIP при 500. Ставки должны закрываться после старта забега, но проверка происходит раньше чтения тела HTTP-запроса.

**Главная ошибка:** Маршрут Axum использует `middleware::from_fn_with_state(..., betting_open)`. Middleware читает `timer < 30` до вызова `next.run(request)`. Сам хендлер `bet` позже разбирает `Json<BetRequest>`. Можно отправить заголовки POST с `Content-Length: 80` и задержать тело. Проверка пропустит запрос до таймера 30, после чего хендлер будет ждать данные. Одновременно `/api/state` отдаёт позиции 16 лошадей, и во время забега уже виден фаворит.
