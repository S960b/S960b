# Ron's Revenge: восстановление ключа RC4-2048 по выбранным IV

[English](solve.md)

## 1. Задача, доказательства и воспроизведение

Сервис шифрует один флаг вариантом RC4 с перестановкой из **2048 элементов**. В KSA подаётся трёхсловный IV, который выбирает клиент, а затем восемь секретных слов. Схема `IV || secret` сохраняет статистическую слабость KSA, даже если увеличить состояние с привычных 256 до 2048 элементов.

**Результат:** флаг получен и принят. Оригинальный FMS-солвер — [`scripts/ronsrevenge_exploit.py`](scripts/ronsrevenge_exploit.py). Он содержит `--selftest`, сбор слабых IV, голосование за восемь слов ключа и проверку на независимых IV. Перед работой с новым инстансом можно запустить `python3 scripts/ronsrevenge_exploit.py --selftest`.

**Источники:** исходный [`server.py`](assets/server.py) и восстановленный солвер. Точные слова ключа из живого сеанса, таблицы голосов и полный терминальный лог не сохранились; их здесь не подменяем догадками.

## 2. Как в действительности работает солвер

В `server.py` размер перестановки — `N=2048=2^11`. RC4 KSA получает ключ вида:

```text
K = [IV_0, IV_1, IV_2, k_0, k_1, ..., k_7]
```

Каждое слово в диапазоне `0..2047`. `IV` присылает клиент, долгосрочный ключ из восьми слов сервер получает один раз с помощью `random.seed(flag)`, а затем использует для всех запросов. Сервер шифрует один и тот же флаг на произвольное число выбранных IV.

**Шаг 1, получить первое 11-битное слово гаммы.** PRGA выдаёт числа по 11 бит, а `Stream.get_prg_byte()` складывает биты в буфер и выделяет из него байты. По известным первым двум байтам флага `PP`:

```python
bits16 = ((ct[0] ^ ord('P')) << 8) | (ct[1] ^ ord('P'))
first_word = bits16 >> 5
```

Тут нельзя просто брать `ct[0] ^ 'P'` и считать это выходом RC4: он только 8 бит, тогда как оригинальное слово содержит 11.

**Шаг 2, слабые IV и FMS-голосование.** Для каждого неизвестного `K[B]`, где `B=3..10`, солвер выбирает:

```python
IV = (B, N-1, x)
# x = 0,1,...,samples-1
```

При `samples=384` это 384 запроса на слово, всего до 3072 запросов. Мы не перебираем все `2048^8` возможных ключей. Поведение первых шагов KSA для выбранных IV даёт статистический перекос; для каждого `x` вычисляется кандидат:

```text
candidate = S_B^{-1}[z] - j_B - S_B[B]  (mod 2048)
```

`S_B` — перестановка после первых B итераций KSA, вычисленная с известным IV и уже восстановленным префиксом ключа. `z` — наблюдаемое первое 11-битное слово PRGA. Значение `candidate` добавляется в таблицу голосов.

Скрипт печатает три лучших кандидата, число голосов победителя и runner-up. Если победитель набрал меньше семи голосов или не превосходит второго минимум вдвое, появляется предупреждение о слабой статистической уверенности. Это не доказательство безошибочности одного IV: результат даёт **накопление большого числа смещённых наблюдений**.

**Шаг 3, обратная проверка.** Сохранены шифртексты для восьми контрольных IV. После восстановления ключа собственная реализация RC4-2048 и упаковки 11-битных слов расшифровывает их. Правильный ключ должен давать **один и тот же plaintext на всех восьми IV** и правильный известный префикс. Это независимая проверка всей цепочки голосования.

## 3. Два способа запуска

```bash
python3 scripts/ronsrevenge_exploit.py --selftest
python3 scripts/ronsrevenge_exploit.py <host> <port> --prefix PP --samples 384
# при низкой уверенности:
python3 scripts/ronsrevenge_exploit.py <host> <port> --prefix PP --samples 512
```

`--selftest` создаёт локальный фиктивный plaintext и собственный `random.Random`, вызывает такой же KSA и проверяет, что все восемь слов восстановлены правильно. В публичной версии фиктивный текст не содержит настоящего флага. Оригинальная рабочая программа восстановлена из файлов прошлого диалога, а не написана по догадке задним числом.

## 4. Почему 2048 элементов не помогли

Размер состояния увеличился с 256 до 2048, однако структура классического KSA с ключом `IV || secret` осталась той же. Вариации выбранного IV сохраняют корреляции между ранней перестановкой и первым выходом. Увеличение разрядности слова не заменяет криптографическую изоляцию ключа и nonce.
