# Litter (misc)

- **Платформа:** HITCON CTF 2026
- **Категория:** Misc (крипта / стега / web-git / ARM64 reverse)
- **Очки / Решений:** 197 очков
- **Дата:** 2026-10-24
- **Remote:** веб-часть на инстансере (замаскирован `<host>`), других сервисов нет
- **Флаг:** `hitcon{too_many..._pudding}` (замаскирован)
- **Файлы:** `assets/flag.png.ltr` (похищенное изображение), `assets/encryptor` (ARM64 ELF из веб-части)
- **Описание (официальное):** "My precious pudding image got ransomed :tear: Someone help me."

Задача - цепочка: скрытые субтитры видео выдают текст `Think outside the box` и URL
поддельного "Litter File Recovery Center"; веб-часть утекает старый SHA-1 Git-архив с
недостижимым коммитом, который хранит подписанную ссылку на релиз; в релизе лежит ARM64
`encryptor`. Сохранённый ELF уже несёт ротированный seed, а шифрование - это AES-192-GCM с
повреждённой S-box (вход >=128 даёт 0). Ключ последнего раунда сокращается в CTR-потоке,
поэтому известные байты PNG (повторяющиеся 16-КБ заголовки IDAT) восстанавливают весь
24-байтовый производный ключ, GCM-тег сходится, и исходная картинка - с флагом -
восстанавливается.

Файлы:

- `solve.md` - полный райтрайт, включая тупики (английский)
- `solve.ru.md` - тот же райтрайт на русском (рабочая копия)
- `scripts/recover.py` - полностью автоматический солвер (проверен: воспроизводит PNG, GCM-тег и CRC)
- `scripts/litter_crypto_verified.py` - восстановленная криптомодель (повреждённый AES-192-GCM)
- `scripts/decode_captions.py` - декодер скрытых сообщений из субтитров YouTube (json3)
- `scripts/get_release.sh` - скачивает подписанный архив релиза из веб-части
- `evidence/VERIFY_RUN.txt` - захваченный вывод солвера
- `evidence/stage3_*` - утёкшие origin/route/signature и лог smoke-теста из старого Git-коммита
