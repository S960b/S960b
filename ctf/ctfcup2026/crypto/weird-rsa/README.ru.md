# Weird RSA

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** крипто
- **Задача:** https://game.ctfcup.online/tasks/weird-rsa
- **Файлы:** `chall.sage`, `output.txt`
- **Флаг:** `ctfcup{...}` (скрыт)

Учебный RSA над кольцом `GF(257)[x]`: флаг читается как коэффициенты многочлена, модуль есть произведение неприводимых степеней 58 и 59, открытый показатель 65537.

Опубликованные степени делают факторизацию ненужной. Функция Эйлера равна `(257^58 - 1)(257^59 - 1)`, значит приватный показатель это один модульный обратный, а расшифровка это возведение многочлена в степень по модулю `N`. Коэффициенты надо читать от свободного члена, как их пишет Sage.

`scripts/solve_weird_rsa.py assets/output.txt` реализует арифметику многочленов над `GF(257)` без Sage, расшифровывает и повторно шифрует для проверки.
