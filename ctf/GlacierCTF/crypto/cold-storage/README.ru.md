## Уязвимость

Веб-сервис использует AES-128-GCM с 96-битным nonce, вычисляемым из `Temporal.Instant`. Строки `1972-12-31T23:59:59Z` и `1972-12-31T23:59:60Z` преобразуются в **один момент времени**, следовательно, получают одинаковый nonce. Однако проверка уникальности времени в `/api/import` сравнивает **исходные строки** и пропускает алиас.

Имея известный открытый текст импорта и публичный архивный шифртекст на одном nonce, можно восстановить ключ GHASH `H`, получить keystream, подделать сообщение `restricted|Ice-VII` и корректный тег GCM. Успешный запрос `/api/open` возвращает флаг (в публичном GitHub скрыт).
