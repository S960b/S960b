# Проверка SafeTrade Research и локальные исправления

Проверен исходный коммит `a9823d92faf2506b0afc2440d2a69fb3999d01b3` из `S960b/S960b`,
каталог `research/safetrade`. Дата проверки: 2026-10-02.
Исправления подготовлены в локальной ветке `fix/safetrade-research`; удалённый репозиторий не изменён.

**Вердикт:** направление исследования разумное. Исходные отчёты нельзя использовать для оценки
преимущества стратегии. Локальная версия проходит проверки исследовательского контура;
подключение к живым биржам и пригодный для исполнения стакан SafeTrade остаются незавершёнными.

## Что агент исправил правильно

- Bybit, Binance и OKX теперь приводят BBO к единому формату bid_price/ask_price.
- Оракул строится по трём внешним источникам с backward-asof, без требования совпадающих часов сообщения.
- Перестали интерполировать цену для исполнения; исчезла подмена неизвестной премии внешней ценой.
- Улучшены имена файлов, схема Parquet, признаки качества и диагностика.
- Статусы сырой и скорректированной целей разделены; long-only явно отражён в симуляции.

При этом 40 проходивших тестов проверяли преимущественно структуру и отдельные формулы,
а не корректность полного исследования.

## Найденные ошибки и внесённые исправления

| Область | Ошибка в проверенном коммите | Локальная корректировка |
|---|---|---|
| Стаканы | prepare_mid_column использовал один OrderBook на все биржи и монеты | Отдельные состояния на run/boot/exchange/symbol; выделенный BBO не смешивается с глубиной |
| Премия | Текущий mid SafeTrade сравнивался с множеством прошлых R | Прошлые пары SafeTrade(u)/R(u); текущая пара исключена; разогрев и возраст учитываются |
| Задержка | Сопоставлялись разные окна с неверным знаком лага | Внешний return [t-W,t] сравнивается с SafeTrade [t-W+lag,t+lag]; +10 действительно означает отставание на 10 с |
| Качество | Invalid-флаги не запрещали расчёт; REST и WS не были синхронизированы | Непригодные события сохраняют барьер; REST-наблюдения изолированы; WS-дельты SafeTrade не изменяют REST-стакан |
| Оракул | Проверялся возраст самого R, но могла уже устареть одна его составляющая | R истекает по первому устаревшему источнику; integer nanoseconds не округляются в float |
| Достижение | Внутренние разрывы считались timeout; already_at_target и отсутствие F0 смешивались | Независимые статусы целей; цензура unknown; первый наблюдаемый hit не выдаётся за точное время пересечения |
| VWAP | В bids_vwap_ts попадал filled, то есть объём, вместо цены | Цена VWAP, точный фиксированный объём и требование полной глубины; REST не допускается в исполнительный тест |
| Paper | Все размеры/задержки складывались; капитал не ограничивался | Отдельный счёт $100 на вариант, одна позиция, комиссии в бюджете, независимый PnL |
| Paper | Будущий стакан мог одобрить вход задним числом; неизвестный выход исчезал | Решение на текущих данных, заранее заданный лимит цены; неизвестные вход/выход сохраняются и блокируют дальнейшую торговлю |
| Запись | Отмена писателя во время to_thread, потери между двумя очередями, тихие ошибки | Единственный последовательный писатель, drain без отмены записи, счётчики, fail-stop, таймер закрытия буфера |
| Raw | Не сохранялся REST-ответ, не было RTT/связи с событиями; неверный байтовый offset | REST raw + request/receive/RTT, raw_ref, UTF-8 байтовые смещения, атомарная компрессия, уникальные имена при повторном run_id |
| Запуски | Разные monotonic-сессии могли смешиваться при загрузке | Одна сессия по метаданным; явный run_id; смешивание нескольких запусков запрещено |
| Панель | Последнее событие любой биржи показывалось как SafeTrade; формат отчётов/сделок не совпадал; обновления не было | Общая нормализация, отдельная таблица бирж, правильный внешний R, отчёты нужного run, CSV, обновление каждые 5 с |
| Развёртывание | Не было requirements; путь к venv и watchdog были жёстко заданными | requirements и проверенные версии, запуск Streamlit через текущий Python, flock на время жизни коллектора |

Комиссия 10 bps теперь отмечена как **непроверенное модельное допущение**.
Отчёты содержат run/boot, конфигурацию, её хэш, ревизию кода и признак локальных изменений.
Старые результаты в репозитории не переписывались.

## Что проверено

- **65 тестов проходят**, включая причинность, изоляцию бирж/монет/сессий, возраст каждой
  составляющей R, нулевую премию на одинаково растущих ценах, лаг +10 с, внутренний разрыв,
  бюджет и комиссии, одну позицию, неизвестные входы/выходы, отсутствие решения по будущему стакану.
- Проверены drain сборщика, связь с raw, потеря писателя, сохранность буфера после ошибки записи,
  имена файлов при повторном run_id и закрытие буфера в тишине.
- Искусственная запись: 2400 событий, 3 внешних источника, SafeTrade повторяет цены с задержкой 10 с.
  Analyze, paper, replay выполняются; на всех трёх источниках лучший лаг +10 с.
- Streamlit проверен с пустой папкой и полной искусственной записью: пять вкладок, таблицы
  котировок/достижения/счетов, без исключений.
- Python compile, git diff --check и синтаксис shell-скрипта проверены.

Искусственный результат проверяет программу и **ничего не доказывает о доходности**.
Модель исполнения условная: полный объём по ограничению цены, один timed exit через H+L;
очереди maker, стопы и частичные исполнения не реализованы.

## Что не получилось подтвердить в живом запуске

Пробный сбор 30 секунд из этой среды:

- SafeTrade REST и WS: HTTP 403;
- Binance WS: HTTP 451;
- OKX/Bybit: отказ WebSocket upgrade (ответ HTTP 200);
- котировок 0, записей health 12, сделок 0, премия недоступна.

Это результат доступности из данной среды, а не доказательство отсутствия API у бирж.
Все ошибки отражены в состоянии. Нужен прогон с компьютера пользователя.
