# LosVault — GlacierCTF 2026

[English version](README.md) · [Технические заметки](solve.ru.md)

**Категория:** web · **Баллы:** 50 · **Статус:** задача решена, флаг принят платформой (по подтверждению участника).

**Какие материалы удалось восстановить:** из старого чата и сохранённого Python-скрипта известно решение по слабому RSA-ключу **внутреннего** TLS-сервиса. Последующий обход роли аудитора, получение конечного флага и точный payload в доступной истории не сохранились. Поэтому это **частичный технический райтап**, а не выдуманная полная цепочка.

[Скрипт Ферма](scripts/losvault_fermat.py) · [Подробности](solve.ru.md)

Внутренний TLS использовал `TLS_RSA_WITH_AES_128_GCM_SHA256` и **RSA-1024**, где `q≈p+2^240`. Простые множители слишком близки: модуль `N=pq` факторизуется методом Ферма практически сразу.

**Важно:** публичный HTTPS front-end использовал обычный **Let's Encrypt RSA-2048**. Его не нужно факторизовать: слабый ключ находится у внутреннего сервиса.
