# Hermes Chat Bridge — мост между ChatGPT и Hermes

## Идея

У нас есть два ИИ с разными сильными сторонами:

- **ChatGPT** (подписка Plus) — «мозг»: безлимитно думает, пишет планы, ревьюит код, разбирает задачи.
- **Hermes** (локальный агент на твоей машине) — «руки»: безлимитно работает с терминалом, файлами, скриптами, API.

По отдельности они не видят друг друга. Мост соединяет их: **гоняет задачи и ответы между мозгом и руками**, чтобы ChatGPT ставил задачи, а Hermes их выполнял и отчитывался — без копипасты текстов вручную.

## Концепция

Мост — это **почтовый ящик (очередь задач)** между ними:

- **Hermes → ChatGPT**: Hermes кладёт в очередь задачу или отчёт.
- **ChatGPT → Hermes**: ChatGPT читает задачу, отвечает или сам ставит новую.

Каждая задача — строка в локальной SQLite-базе с уникальным `job_id` (например `test_1f1a1e9a.job`). ChatGPT подключается к мосту как MCP-плагин и работает с очередью через простые инструменты:

- `bridge_get_message` — прочитать задачу по job_id
- `bridge_put_reply` — ответить на задачу
- `bridge_put_message` — поставить новую задачу Hermes
- `bridge_subscribe` / `bridge_unsubscribe` — подписка на события (для авторежима)

Доступ защищён OAuth: плагин логинится (пользователь `owner` + пароль), без токена мост отвечает 401.

Снаружи мост виден по **постоянному адресу** `https://kali.tail12eeb2.ts.net` (MCP: `.../mcp`) — его даёт Tailscale Funnel, адрес не меняется.

## Реализация

Всё крутится на одной Kali-машине как сервисы (автозапуск через systemd):

| Сервис | Что делает |
|---|---|
| `hermes-bridge.service` | MCP-сервер моста, порт 8765 (только localhost) |
| `hermes-taskboard.service` | таск-борд, порт 8787 — визуальный список задач в браузере |
| `tailscaled.service` | Tailscale Funnel: публичный адрес `https://kali.tail12eeb2.ts.net` → 8765 |

**Таск-борд** (`http://127.0.0.1:8787`) — твоя панель: видно все задачи, статусы, фильтры, и у каждого job_id есть кнопка «⧉» — скопировать id одним кликом и переслать ChatGPT.

**Как это работает сейчас:**
1. Hermes (или ты) кладёт задачу: `bridge_cli put "текст"`.
2. Ты (или авторежим Work) передаёшь ChatGPT полный job_id — копией из таск-борда.
3. ChatGPT читает задачу, делает свою часть («мозг»), отвечает — `bridge_put_reply`.
4. Hermes видит ответ, забирает и выполняет («руки»), кладёт отчёт — цикл повторяется.

В режиме **Work** ChatGPT подписывается на события моста и просыпается сам, без передачи job_id вручную — полный автопилот.

**Проверка, что всё живо** (после ребута или если что-то молчит):

```sh
curl http://127.0.0.1:8765/ping                  # мост жив
curl https://kali.tail12eeb2.ts.net/ping         # публичный адрес жив
systemctl is-enabled tailscaled                  # должен быть enabled
```
