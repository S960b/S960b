# Исходники Binance Spot Copy audit

**ВНИМАНИЕ:** `audit_public_scrubbed.py` — **DERIVED/CENSORED**, а не исходный исполнявшийся файл. Он оставляет публичные `time`, `exchangeInfo`, `depth`, но намеренно не умеет выполнять подписанные запросы к Binance и не содержит загрузчик ключей. Восстановленный из Git-диалога оригинал имел другой SHA.

- Оригинальный read-only audit: SHA256 `97e803f2db832bd011f532d71f585fe17477e76862d73ecbe3974fa0342aedc1`, 8968 байт; исходник в публичный Git **не переносился**. В нём было чтение внешнего `--credentials-file` (ключ не был встроен в сам код) и подписанные endpoints `account/apiRestrictions` и `account/commission`.
- Публичный вариант: SHA256 `f322557a5c0b7d37c781da70e3f90f389b020c8fa6f84454c506083a29900fda`, 6507 байт. Архивирован побайтно из приватного `archival_sources/binance_copy/audit_public_scrubbed.py`, commit `f91c2d54bd357f87b50667ddbc192c99d596cf7a`.
- Для запуска публичного варианта: `python3 audit_public_scrubbed.py --output public_audit.json`. Он использует живые **публичные GET**, поэтому результаты и доступность рынков могут отличаться от отчёта MT от 5 ноября.
- `LEADER_BALANCE` и `EXAMPLES` в скрипте — исторические иллюстративные значения со снимка лидера, не баланс или ордера владельца репозитория.

Следовательно, публичный вариант **не воспроизводит приватную проверку ключа и аккаунтных комиссий**. Не выдавайте его результат за полное повторение оригинального эксперимента. Никаких ключей/аккаунтных файлов в этот архив не добавлено.
