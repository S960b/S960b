# MMM: собственный вектор вместо перебора флага

[English](solve.md)

## 0. План

Исходным файлом был ELF64 из `mmm.zip`. Строка флага не лежала открыто в `strings`. Я искал проверку ввода и данные, которые она использует.

Цепочка решения: таблица в `.rodata`, матрица 40 на 40, собственное значение 1337, восстановление собственного вектора, интерпретация ASCII, проверка SHA-256 и успешный запуск бинаря.

## 1. Поиск числовых данных

```bash
file mmm
readelf -S mmm
objdump -s -j .rodata mmm | head -80
```

В секции только для чтения обнаружились **1600 элементов**. Их удалось организовать в матрицу из 40 строк и 40 столбцов. Проверка в программе была связана с собственным значением **1337**:

```text
M * v = 1337 * v
(M - 1337 * I) * v = 0
```

Здесь `v` и есть интересующий нас вектор. Для его нахождения не нужно перебирать все символы строки, достаточно найти ненулевой вектор в ядре `M - 1337 I`.

## 2. Точное решение

Если числа целые, я бы не использовал обычный `numpy.linalg.eig` как финальную проверку, поскольку он работает с приближёнными float. В SymPy можно найти ядро точно:

```python
import json
from sympy import Matrix, eye

rows = json.load(open("matrix.json"))
assert len(rows) == 40 and all(len(row) == 40 for row in rows)
M = Matrix(rows)
basis = (M - 1337 * eye(40)).nullspace()
print(basis)
```

Полученный вектор может быть задан с произвольным множителем или знаком. Перед чтением ASCII нормализуем его и ещё раз проверяем матричное равенство без ошибок округления.

В сохранившейся переписке нет полного дампа матрицы и её оффсета, поэтому здесь приведён воспроизводимый метод, но не выдуманная таблица.

## 3. Получение строки

Компоненты собственного вектора были интерпретированы как символы. Кандидат соответствовал формату `ctfcup{...}`, а SHA-256 совпал с проверкой бинаря. После запуска с правильным вводом программа напечатала:

```text
The seal breaks. Carry what you brought to the gate.
```

Код возврата был **0**. Задача MMM была сдана командой.

## 4. Главное

Это хороший пример, когда полезнее восстанавливать математику проверки, чем патчить переходы или бесконечно гонять отладчик. Матрица, значение 1337 и точное линейное уравнение дают структуру решения. Полный флаг в публичной версии скрыт, по правилам соседнего раздела Solar.
