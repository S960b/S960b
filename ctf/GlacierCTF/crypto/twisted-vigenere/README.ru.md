# Twisted Vigenere — GlacierCTF 2026

[English version](README.md) · [Полный технический райтап](solve.ru.md)

**Категория:** crypto · **Баллы:** 50 · **Статус:** решено, флаг принят платформой (подтверждение участника).

Название вводит в заблуждение: внутри не классический Виженер, а **XOR с циклически повторяющимся флагом**, наложенный на `random.randbytes(2536)` из Python (MT19937).

## Воспроизведённый результат

На оригинальном архиве организаторов независимо получено:

```text
gctf{from_rand0m_!mpor+_n0+_s0_r4nd0m_af+3r_???}
```

Это **45 из 48 байт**. Последние три перед `}` по доступным выходам MT19937 не определяются; их восстанавливает принятый ранее платформой флаг. Весь принятый ключ успешно проходит **320 битовых уравнений** MT19937 с **нулём расхождений**.

Это важное ограничение: не утверждаем, что исходный ciphertext однозначно определяет абсолютно все 48 байт.
