# Unholy Trinity

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** Platypwn 2026
- **Категория:** crypto
- **Сложность:** 2
- **Материалы:** `server.py`, Dockerfile, compose; saved solver invocation (solver file itself absent)
- **Флаги:** 2 принято, полные строки скрыты (`PP{...}`)

В самодельной RSA-аутентификации было две независимые ошибки: модульный хэш пароля и доказательство знания короткого секрета.

**Суть:** Сервер задаёт `e=17`, RSA-модуль `N` примерно на 2674 бита и хранит `hash_pw(pw) = int(pw)^17 mod N`. Разные числа, сравнимые по модулю N, дают одинаковый хэш. У `admin` секрет всего 19 байт: для такого `m` выполняется `m^17 < N`. Сервер печатает `pw_hash` до раундов, значит точный целочисленный корень степени 17 раскрывает секрет без факторизации N.
