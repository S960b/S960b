# Snake

[English](README.md) | [Путь решения](solve.ru.md)

- **Событие:** отбор CTFCUP 2026
- **Баллы:** 100
- **Категория:** misc / автоматизация игры
- **Задача:** https://game.ctfcup.online/tasks/snake
- **Файлы:** браузерный клиент (сохранённая копия использовалась при разборе протокола)
- **Флаг:** `ctfcup{...}` (скрыт)

Гексагональная змейка с `radius: 4` и `target: 61`. У поля радиуса 4 число клеток `3R^2 + 3R + 1`, то есть цель это всё поле: змейка должна занять каждую клетку.

Клиент общается обычным WebSocket: наружу `{"type":"move","dir":0..5}`, внутрь `{"type":"state", ...}`. Жадный поиск до еды запирает себя на длине 25-34, поэтому рабочий подход это заранее построенный гамильтонов цикл: тело остаётся последовательным отрезком, голова не выбирает, а прогон заканчивается примерно через 1040 ходов состоянием `won: true` и флагом в поле `message`.

Скрипты: `scripts/hamilton.py` строит цикл, `scripts/hamilton_bot.py` играет.
