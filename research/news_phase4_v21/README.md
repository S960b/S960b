# NEWS Phase 4 v2.1 — публичный аудит-пакет

Статус: **технический пакет для независимого аудита**. Это не отчёт о доходности
и не доказательство предсказательной силы (alpha). Задание аудитору пишет
ChatGPT и оно лежит рядом: [`AUDITOR_PROMPT_RU.md`](AUDITOR_PROMPT_RU.md) —
читайте его первым, здесь только материалы.

## Что здесь

| папка | содержимое |
|---|---|
| `source/` | **весь код**, который реально работал: ингест, селектор, подготовка промптов, диспетчеризация квот, плагин, раннер, определение restricted-агента |
| `scripts/` | офлайн-инструменты: экспорт, снапшот, сверка расходов, маркировка пилота |
| `tests/` | все тесты, включая регрессии на утечку будущего, якорь 4h-метки и fail-closed парсер |
| `docs/` | протокол аудита с предрегистрацией H1–H5, словарь данных, датированный таймлайн |
| `data/` | санитизированные read-only выгрузки, включая первую созревшую 4h-метку: события, пары, ответы рук с хешами, цены входа, расходы по сессиям |
| `MANIFEST.sha256` | SHA-256 каждого файла пакета |

## Состояние на 2026-11-17: что работает, а что нет

Этот раздел добавлен, потому что формулировка «пакет для аудита» легко читается
как «всё стоит». Статусы разные и их нельзя смешивать:

| что | состояние | доказательство |
|---|---|---|
| legacy-коллекторы v2.1 и Phase-4 v2 | **РАБОТАЮТ** | `news-v21-plugin.log` пишется каждые 30–60 с; `news-p4-v2-plugin.log` тоже свежий |
| леджер продакшена | **РАБОТАЕТ** | 6 записей, 6/6 меток созрели |
| процесс GUI | **РАБОТАЕТ** | pid 3391340, стартовал 2026-11-16 17:04 |
| все исправления стадий 1–2C и v2.2/v2.4 | **НЕ ЗАГРУЖЕНЫ** | загруженная сборка старше любого из них |
| хук сеттла пилота | **НЕ ЗАГРУЖЕН** | `v21_pilot_settle` = 0 строк в логе |
| инференс модели | **ПАУЗА** | флаг `PAUSED_MODEL_INFERENCE` на месте |
| проспективные v2.2 / v2.4 | **НОЛЬ** | данных нет, счётчик пуст |

Короче: старый эксперимент жив и пишет метки, новый код нигде не исполняется,
инференс остановлен. Выражение «ничего не запущено» было бы неправдой.

**Статус пакета: кандидат на офлайн-аудит, НЕ готов к продакшену.**
Вердикт «код и методология — GO» относится только к офлайн-контракту на
синтетических фикстурах. Он ничего не говорит о прогнозной силе, качестве
живых данных, лицензиях источников или доходности — и не должен так читаться.

## Что проверяет эксперимент

Две руки на одном и том же событии и одном моменте решения:

- **N** — только новость;
- **NM** — та же новость плюс признаки BTC по 1h-свечам, закрывшимся **строго до**
  момента решения.

Горизонт — 4 часа. Гипотезы H1–H5 (Brier, ошибка ожидаемой доходности,
сравнение с рыночным и базовым бейзлайном, стратификация по когортам без
объединения) предрегистрированы в [`docs/NEWS_V21_AUDIT_PROTOCOL.md`](docs/NEWS_V21_AUDIT_PROTOCOL.md)
до набора проспективных данных.

## Что уже установлено и что нет

**Установлено:**

- реальные вызовы DeepSeek работают, идентичность модели видна в ответе
  (`deepseek / deepseek-v4-flash`);
- метка 4h берётся по первой публичной 1m-свече, закрывшейся **не раньше**
  `due`, дрейф ≤ 60 с, старая цена до горизонта не используется;
- журнал неизменяемый: повторная запись отклоняется, метка пишется один раз;
- расход считается раздельно: резервы, завершения провайдера, токены, стоимость,
  вызовы инструментов.

**ПРОВАЛЕНО / Не установлено:**

- **запрет инструментов НЕ действует.** Назначение агента `news-restricted`
  записывается в сессию корректно, но в этих же сессиях зафиксированы реальные
  вызовы инструментов, включая `websearch` (`df3eb36487c1`, `c377be7226e9`), а
  также `memory` и `skill`. Изоляция правом агента не достигается. Поэтому
  информационное множество НЕ считается запечатанным, H1–H5 заблокированы, а
  проспективная выборка пуста. Пакет передаётся аудитору для **анализа причин
  отказа**, а не для подтверждения результата.
- **проспективных пар: 0.** Ни одна записанная пара не является audit-grade.
- предсказательная сила — проспективных событий пока единицы, порог протокола
  для любого направленного утверждения — 200 независимых событий;
- стабильность доли отказов: на 4 попытки пришлось 2 отказа (один — строгость
  парсера, один — усечённый ответ модели).

**Пилотные наблюдения** (пары `40d21dd674c8`, `e0c7b377a018`, `d619c25574da`)
собраны до запрета инструментов и помечены как `PILOT_DISCOVERY`; в
проспективную выборку они не входят. Первая проспективная пара —
`f89bc542ffdd` (10:53:35Z, `tools = 0`).

## Чего здесь нет и почему

- нет `opencode.db` — в нём личные разговоры владельца, не относящиеся к делу;
- нет промптов целиком и обоснований модели — вместо них SHA-256 промпта и
  ответа, этого достаточно для сверки неизменности;
- нет полных текстов статей — только усечённый заголовок, источник, время и URL,
  чтобы аудитор мог убедиться, что событие существовало;
- нет ключей, токенов и приватных эндпоинтов — их не было в работе изначально.

Как аудитору сверять: [`MANIFEST.sha256`](MANIFEST.sha256) + `data/export_*.json`
+ `docs/AUDIT_DATA_DICTIONARY.md`. Все экспорты read-only и содержат
`quick_check` каждой базы.

## PROMPT_ONLY пилот — что это и чего это не доказывает

Отдельная версия заголовка `prompt-only-pilot-v1` добавляет в обе руки одно и то
же указание: не вызывать websearch/webfetch/memory/skill/shell, пользоваться
только замороженным JSON, новости считать данными, отвечать одним строгим JSON.
Указание стоит **до** любого текста события. Предрегистрированный заголовок
`prospective-v1` не изменён — это отдельная версия, а не правка протокола.

| утверждение | статус |
|---|---|
| модель **попросили** не использовать инструменты | реализовано; соблюдение наблюдалось на одиночных пробах |
| набор инструментов **принудительно недоступен** | **НЕ доказано** |
| строгий статистический аудит допустим | **НЕТ** — строки пилота помечаются `PILOT_PROMPT_ONLY` |

H1–H5 остаются заблокированными, проспективная когорта — 0.

## Границы этого пакета

Предрегистрированный протокол `docs/NEWS_V21_AUDIT_PROTOCOL.md` **не переписан**.
В его конце есть датированное дополнение, которое перечисляет правила, ставшие
неактивными (изоляция инструментов, денежные пороги), и порядок версионирования
нового протокола. Исторические строки данных не перемаркируются.

**Изоляция инструментов НЕ установлена.** Пилотные пары собраны под указанием
«не вызывать инструменты» и помечены `PILOT_PROMPT_ONLY`; это соблюдение
инструкции, а не отсутствие инструментов. Проспективная когорта — 0.

## Критерий допуска (fail-closed)

`scripts/v21_toolpreflight.py` возвращает GO (exit 0) **только** при позитивном
техническом доказательстве: часть инструмента со статусом `error`, где текст
ошибки — отказ по правам. Всё остальное — INCONCLUSIVE:

- модель сама написала «отказано» без попытки вызова — не доказательство;
- сетевая ошибка инструмента — не отказ по правам;
- вообще нет частей инструментов — не доказательство.

Отсутствие вызова и самоотчёт модели не считаются никогда.

Воспроизведение офлайн

```bash
# 1) Python-тесты (без сети, без модельных вызовов)
#    модули лежат в source/, поэтому PYTHONPATH обязателен
PYTHONPATH=source python3 -m unittest discover -s tests -p 'test_v21_*.py'
#    → Ran 167 tests ... OK

# 2) Node-тесты (мок-SDK, временные каталоги, сеть не нужна)
cd tests
node --test test_v21_paper_runner.mjs test_v21_service.mjs probe_test.mjs
#    → # tests 22 / # pass 22 / # fail 0

# 3) целостность пакета
cd .. && sha256sum -c MANIFEST.sha256        # 60 файлов, 0 ошибок

# 4) пересборка экспорта из копии баз (read-only)
PYTHONPATH=source python3 scripts/v21_export.py \
  --data-dir /path/to/copy --out export.json

# 5) снапшот и сверка расходов
python3 scripts/v21_snapshot.py --out snapshot.json
python3 scripts/v21_usage.py
```

Полный лог прогонов из чистого клона: [`VERIFICATION.md`](VERIFICATION.md)
(199 Python-тестов, 24 Node, 61 хэш на коммите `9cbface`).

Один модуль в `source/` стоит объяснить: `v21_service.mjs` — **отключённый
исторический супервизор**. Он прогоняет цикл без модельного клиента и оставлен
только ради своих тестов; в продакшене он не работает (`inactive + disabled`).
