# Carbon

[English](README.md) | [Решение](solve.ru.md)

- **Категория:** fullpwn
- **Сложность:** 1
- **Материалы:** Два флага подтверждены итогами решения; статической раздатки, полного эксплойта и терминального лога нет
- **Флаги:** 2 принято (`PP{...}`)

Машинная задача с двумя флагами. По отчёту пользовательский флаг связан с повторным использованием кэшированной сессии, root-флаг — с окружением оператора.

**Главная ошибка:** В кратком отчёте есть две границы доверия: приложение, принявшее старую сессию из кэша, и привилегированное окружение оператора с секретом. В старых обсуждениях дополнительно исследовалась поверхность Next.js/React Flight. Однако окончательных логов и исходников окружения нет: нельзя доказать, что этот отдельный путь RCE был частью успешного решения.

Подробнее — в [решении](solve.ru.md).
