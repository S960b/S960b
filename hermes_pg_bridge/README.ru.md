# Hermes PostgreSQL Bridge — исходники для независимого аудита

[English](README.md) · [Предыдущий мост на Git](../hermes_chat_bridge/)

**Статус на 24 ноября 2026: сбор исходников и манифеста ещё идёт.** Пока материалы не выгружены полностью, этот каталог не является завершённым аудитным пакетом.

## Назначение

Мост между ChatGPT и локальным Hermes/MultiTool с PostgreSQL как авторитетным журналом сообщений и доставок. ChatGPT проектирует решения, пишет код и принимает отчёты; локальный агент выполняет конкретные команды, отправляет результаты. Управляемая очередь обеспечивает последовательность сообщений, очередность ходов, lease и подтверждения.

Компоненты: MCP edge и guard, локальный managed Inbox, PostgreSQL, Taskboard на loopback-порту 8789, SSH-туннель, watchdog и ограниченные рабочие сеансы Stage 39.

## Что будет в аудитном экспорте

Исходники сервиса Python и SQL; код MCP и ограничения доступа; плагин Inbox; установочные скрипты/шаблоны systemd; Taskboard/UI; тесты; исторические этапы и манифест, отделяющий действующий код от устаревшего.

**Нельзя публиковать в этом публичном репозитории:** работающие ключи и пароли, содержимое conninfo/opencode.json, .env, закрытые SSH-ключи, приватные журналы диалогов, дампы БД, session/permit/receipt, логи и иные персональные данные. Для проверки безопасности используются обезличенные шаблоны и описания, а не секреты.

## Подтверждённое и ограничения

Stage 39 проверен на двух последовательных заданиях через один рабочий сеанс с подтверждённой доставкой отчётов. Надёжность автоматического продления на протяжении полного шестичасового периода ещё не доказана. Автоматическое восстановление неопределённого SQL claim — технический долг.

Исторические скрипты — материалы для анализа, а не команды для запуска на действующей машине.

После окончания выгрузки манифест укажет версии, хеши и состав материалов.
