# Flagchecker (reverse engineering)

[English version](README.md) · [GlacierCTF 2026](../../README.ru.md)

В исходном архиве `flagchecker.tar.gz` находился ELF-бинарник `challenge`. Цель — найти флаг, который принимает эта программа.

В сохранившемся отчёте о решении зафиксированы 1337 строк, закодированных XOR, однобайтовый ключ `0x12` и правильный флаг, связанный с записью №706. Оригинальная программа ответила `The flag is valid!` на восстановленное значение.

## Файлы

- [solve.ru.md](solve.ru.md): подробный ход решения и порядок воспроизведения.
- [scripts/solve.py](scripts/solve.py): восстановленный экстрактор кандидатов с возможностью локальной проверки.
- [assets/README.md](assets/README.md): состояние оригинальных материалов.

На момент оформления райтапа исходный архив и точный журнал команд восстановить не удалось. Автор, количество баллов и дословное условие в сохранившейся записи отсутствуют. Скрипт написан заново по известным результатам. Успешная локальная проверка зафиксирована во время соревнования.

Полный флаг замаскирован как `gctf{...}`.
