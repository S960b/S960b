# Matryoshka

[English](README.md) | [Решение](solve.ru.md)

- **Соревнование:** Platypwn 2026
- **Категория:** rev
- **Сложность:** 1
- **Материалы:** ELF binary `matryoshka`; preserved CRC recovery command
- **Флаги:** 1 принято, полные строки скрыты (`PP{...}`)

Многослойный ELF: полезные данные лежали не в открытой строке, а внутри последующих слоёв.

**Суть:** После снятия слоёв были найдены четыре ограничения CRC32 на 4-байтные части 16-байтного пароля. В логе зафиксированы значения `0x6d795f63`, `0x30306c5f`, `0x70343473` и `0x77307264`. CRC32 аффинен над GF(2), поэтому влияние каждого бита можно посчитать и обратить систему обычным исключением Гаусса по модулю два.

Подробности — в [решении](solve.ru.md).
