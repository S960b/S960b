# MeowSim: статический разбор Android-приложения

[English](solve.md)

## 0. Подход

В описании нужно ухаживать за квантовым котом, а наблюдатель меняет его судьбу. Я не стал воспроизводить длинную цепочку нажатий в эмуляторе. Сначала посмотрел, какие условия непосредственно проверяет код перед выдачей флага.

## 1. Распаковка и декомпиляция

APK это ZIP с `classes.dex`. Для быстрого чтения логики подходит JADX:

```bash
file cat.apk
unzip -l cat.apk | head -40
jadx -d out cat.apk
grep -R -nE 'QuantumState|FlagVault|canOpenFlagVault' out/
```

## 2. Условие открытия

Ключевой метод `QuantumState.canOpenFlagVault()` требует одновременно:

```text
catAlive       == true
catDead        == true
superposition  == true
stability      >= 90
observed       == false
tampered       == false
```

В игровом мире это звучит нелогично, но для программы это обычная проверка шести полей. Живой и мёртвый одновременно кот допустим при установленном флаге суперпозиции. А вот наблюдать его нельзя: `observed=true` ломает условие.

## 3. Как прячется флаг

`FlagVault` не содержит флаг в открытом виде. Он использует SHA-256 для получения ключевого материала и XOR для расшифрования **23 байт** встроенных данных. Поэтому нельзя ограничиться поиском `ctfcup{` через `strings`.

Для восстановления нужны исходные байты, точная сериализация полей состояния, хеш SHA-256 и XOR по байтам. Сам принцип:

```python
plaintext = bytes(c ^ k for c, k in zip(ciphertext, keystream))
```

Но это только объяснение, не полный солвер: исходные константы DEX в сохранившейся переписке отсутствуют.

## 4. Найденное состояние

Подошла `stability=92`. Кот должен быть одновременно жив и мёртв, суперпозиция включена, наблюдение и вмешательство выключены. Из этих условий и внутреннего шифрования получились 23 байта корректного `ctfcup{...}`. Задание сдано командой.

## 5. Вывод

Здесь выиграл не перебор действий, а чтение условий. Подсказка с наблюдателем действительно важна, но в обратном смысле: его не должно быть. Для полного байтового реплея нужен оригинальный `cat.apk`; выдумывать отсутствующие константы было бы неправильно.
