Лабиринт на Python 3.15: тысячи сгенерированных модулей комнат (`m/x_*.py`), комнаты
буквально двигаются и переставляют стены, когда ты их посещаешь, а выход выполняет
`exec(state.script)` - строку, которую ты копил с каждым шагом. Фишка - новые
`sys.set_lazy_imports` / `sys.set_lazy_imports_filter` из Python 3.15, которые ставит
сервер: эффекты комнаты срабатывают только когда модуль реально (жадно) импортирован,
так что поиск маршрута, собирающего нужный скрипт, - это поиск по лабиринту плюс тайминги
импортов. Победная нагрузка - строковый литерал `"JQ\",~"+breakpoint()`: `breakpoint()`
открывает PDB на сервере раньше, чем произойдёт ошибка типа, а PDB - это удалённый
python-шелл.
