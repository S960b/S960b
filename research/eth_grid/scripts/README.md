# Исходники ETH Grid

- `grid_shadow.py` — **оригинальный неизменённый** скрипт MT, которым выполнен 30-дневный публичный экономический скрининг Binance ETHUSDT.
- SHA256 исходника: `338fc6c946ff5a87bc4fa0c1329051d9c5a60721c1995535b77c207a64591387`.
- `../eth_30d.json` — исходный результат того запуска с SHA256 `3804a92197e111fed69b400253cca2aee7b400b1865c13824a8935951281c144`.
- Источник восстановления: приватный репозиторий `S960b/agent-dialogs`, commit `f91c2d54bd357f87b50667ddbc192c99d596cf7a`, архив `archival_sources/eth_grid/`. Git blob оригинала сохранён без изменений.

Пример исследовательского запуска (GET публичных свечей, без торговых операций):

```bash
python3 grid_shadow.py --eth 1 --days 30 --out ./eth_30d_new.json
```

Повторный запуск на текущих данных **не воспроизведёт** исторический срез 2026-10-06..2026-11-05. Для фиксированной ретроспективы используйте `--start-ms` и `--end-ms` из протокола, а для сверки исходной работы — сохранённый JSON и его `market_sha256`.

Ограничение: это упрощённая виртуальная стратегия с ценами `previous close / next open`, а не реальный Binance Grid execution backtest.
